# 03 — 검색 범위에 기능 이름 확인 + ESC 로 검색어 지우기

**Blocked by:** 🟢 **없음 — 지금 착수 가능.**

**Status:** resolved (2026-09-02)

## What to build

**기능 이름(feature 명)이 검색 범위에 있는지 확정하고, 없으면 넣는다.** 화면의 기능 카드에
보이는 이름 — `feature.title`(spec H1 표제, 예: "계획은 판 위에서 움직인다")와 `feature.slug`
(폴더명, 예: "plan-board") — 둘 다 검색어로 찾을 수 있어야 한다.

> 직전 작업(2026-09-02, 커밋 `7c4f4de`)에서 `filterFeaturesBySearch` 에 `feature.slug`
> 매칭을 이미 넣었다. 이 티켓은 그 사실을 **명시로 확정**하고, feature name 매칭이 실제로
> 일어나는지 테스트로 박는다.

**ESC 단축키.** 검색 상자에 포커스가 있을 때 `ESC` 를 누르면 검색어가 지워지고
원래 목록으로 돌아온다. 지우기 단추를 마우스로 찾는 대신 키 하나로 되돌릴 수 있다.

## 왜

**슬러그가 필요했던 실제 결함(2026-09-02).** `plan-board`(title="계획은 판 위에서
움직인다")와 `development-order`(title="개발 순서를 gootte 가 관리한다")처럼 title 이
slug 를 포함하지 않는 기능은, 화면 카드의 배지(slug)로 보이는 기능 이름을 검색어로
넣으면 **전혀 검색이 안 됐다.**

**ESC 는 검색을 자주 쓰는 캡틴의 자연스러운 동작이다.** 지우기 단추를 클릭하는 대신
ESC 한 번으로 깔끔하게 되돌릴 수 있어야 한다.

## 어떻게 찾나 (변경 없음 — 기존 규칙 그대로)

- 대소문자 무관 부분 일치
- 정규식 아니므로 특수문자 안 깨짐
- 서버 재호출 없음(이미 와 있는 값을 거른다)
- 기능 이름(`feature.title`) + 슬러그(`feature.slug`) + 티켓 제목 — 모두 범위

## 문구 (변경 없음)

- 상자 안 안내 글자: `기능·티켓 검색`
- 아무것도 안 걸렸을 때: `찾는 것이 없습니다`
- 지우기 단추 보조기술 이름: `검색어 지우기`

## 완료 조건

- [ ] 🔴 **기능 이름(feature.title)으로 검색된다** — 대소문자 무관, 부분 일치
- [ ] 🔴 **슬러그(slug)로 검색된다** — title 이 slug 를 포함하지 않는 기능도 찾는다
- [ ] 🔴 **ESC 를 누르면 검색어가 지워지고 원래 목록으로 돌아온다**
- [ ] 🔴 **ESC 후에도 포커스는 상자에 남는다** — 다시 입력하려면 클릭할 필요 없다
- [ ] 기존 동작이 그대로 산다 — 티켓 제목 검색, 노란 칩, 안 걸리면 없다고 말함, 지우기 단추
- [ ] `pnpm verify` green

## 이 티켓이 하지 않는 것

- **가상 스크롤 검색** — 02 가 이미 한다.
- **문서 본문 검색** — 캡틴이 범위를 이름과 제목으로 정하셨다([spec](../spec.md) §열린 결정).
- **계획 탭·단계 탭·문서 트리 검색** — 범위 밖.
- **서버 검색 · 새 API** — 값은 이미 와 있다.
- **검색어 기억하기 · 최근 검색** — 지시에 없다.
