# 01 — 검색 상자가 기능과 티켓을 찾아 준다

**What to build:** `features` 탭 목록 위에 **검색 상자**가 선다. 캡틴이 글자를 넣으면
**기능 이름**과 **티켓 제목**으로 목록이 걸러진다. 🔴 **접힌 카드 안의 티켓까지 걸린다** —
브라우저 찾기가 오늘도 못 하는 일이다.

**Blocked by:** 🟢 **없음 — 지금 착수 가능.**

**Status:** claimed

## 캡틴 지시 (원문)

> **"cmd + f가 필요하다면, 차라리 검색 폼을 두는게 났지 않겠어?"**

범위는 캡틴이 정하셨다 — **기능 이름 + 티켓 제목**까지. 문서 본문은 범위 밖이다.

## 왜 — 브라우저 찾기는 이 화면에서 이미 반쪽이다

카드는 기본이 접혀 있고, 접힌 카드 안 티켓은 **화면에 아예 없다**([spec](../spec.md) V1·V5).
그래서 ⌘F 가 찾는 것은 기능 이름·슬러그·수치뿐이다 — jinwooauto 기준 **티켓 81장 중
펼쳐 둔 것만** 찾힌다.

🟢 **검색 상자는 그것을 고친다.** 티켓 제목은 접힌 카드도 이미 갖고 있다([spec](../spec.md) V9) —
🔴 **서버를 새로 부르지 마라.** 이미 와 있는 값을 거를 뿐이다.

🔴 **그리고 이 티켓은 [02](02-the-feature-list-renders-only-what-is-on-screen.md) 의 전제다.**
02 는 화면 밖 카드를 목록에서 빼므로 ⌘F 가 통째로 죽는다. **이것이 먼저 서 있어야
캡틴이 찾을 길을 잃지 않는다**([spec](../spec.md) §순서 · INV-V4).

## 걸러진 목록은 무엇을 보여 주나

- **기능 이름이 걸리면** 그 카드가 **그대로** 뜬다(평소 모습).
- 🔴 **티켓 제목이 걸리면 그 카드가 펼쳐진 채로 뜨고, 걸린 티켓이 보여야 한다.**
  접힌 채로 두면 캡틴이 **왜 이 카드가 걸렸는지 모른다** — 그러면 카드를 하나씩 열어 봐야 하고,
  검색이 한 일이 절반만 남는다.
- **아무것도 안 걸리면** 없다고 **말한다.** 🔴 빈 화면으로 두지 마라 — 빈 화면은
  "고장 났나" 와 구분되지 않는다.
- 🔴 **목록 위의 미해소 사본 구역은 검색과 무관하게 그대로 선다**([spec](../spec.md) V2).
  그것은 목록이 아니라 경고다 — 검색어로 숨기면 캡틴이 못 보게 된다.

## 어떻게 찾나

- **대소문자를 가리지 않는다.**
- **부분 일치**다 — 가운데 글자만 넣어도 걸린다.
- 🔴 **한글 조합 중에 화면이 널뛰지 않게 한다.** 한글은 글자를 조립하는 중간 상태가 있어,
  타이핑 한 획마다 목록을 다시 그리면 캡틴 눈에 화면이 떨린다.
- 🔴 **정규식·특수문자를 캡틴이 넣어도 깨지지 않는다.** 검색어는 글자로 다루지 규칙으로 다루지 않는다.

## 어디에 서나

목록 **위**, 미해소 사본 구역과 카드 목록 **사이**가 아니라 **둘 다의 위**다 —
검색은 목록 전체를 다루는 것이고, 스크롤을 따라 사라지면 긴 목록에서 쓸 수 없다.

🔴 **스크롤해도 검색 상자가 화면에 남아야 한다.** 목록이 길어질 때를 대비하는 기능인데
검색 상자가 위로 밀려나 사라지면 그 목적이 무너진다.

## 문구 (사람이 읽는 것이라 그대로 쓴다)

- 상자 안 안내 글자: **`기능·티켓 검색`**
- 아무것도 안 걸렸을 때: **`찾는 것이 없습니다`**
- 지우기 단추의 보조기술 이름: **`검색어 지우기`**

🔴 **"필터" · "Search" 로 쓰지 마라** — 이 화면의 다른 글자가 전부 우리말이다.

## 주소에 실을 것인가

🔴 **싣지 마라.** 이 탭은 이미 주소에 열린 문서를 싣고 있다 — 검색어까지 실으면
캡틴이 문서를 열 때마다 주소가 길어지고, 새로 고침 때 **의도치 않게 걸러진 목록**으로 돌아온다.
검색은 지금 이 순간의 일이지 저장할 상태가 아니다.

## 완료 시 시연 가능한 것

**누가, 어디서, 무엇을** — **캡틴이 `features` 탭**에서 확인한다. 매일 여는 자리다.

1. 상자에 기능 이름 일부를 넣는다 → **그 카드만 남는다.**
2. **접힌 카드 안에만 있는 티켓 제목**을 넣는다 → 그 카드가 **펼쳐진 채로 뜨고,
   걸린 티켓이 보인다.** ⌘F 로는 안 되던 일이다.
3. 없는 말을 넣는다 → **찾는 것이 없다고 말한다.**
4. 검색어를 지운다 → **원래 목록 그대로 돌아온다.**
5. 목록을 아래로 스크롤한다 → **검색 상자가 그대로 보인다.**
6. 검색 중에도 **미해소 사본 경고는 그대로 서 있다.**

## 완료 조건

- [ ] 🔴 **기능 이름으로 걸러진다** — 대소문자 무관, 부분 일치
- [ ] 🔴 **티켓 제목으로도 걸러진다 — 접힌 카드 안 티켓까지**
- [ ] 🔴 **티켓 때문에 걸린 카드는 펼쳐진 채로 뜨고 걸린 티켓이 보인다**
- [ ] 🔴 **아무것도 안 걸리면 없다고 말한다** — 빈 화면으로 두지 않는다
- [ ] 🔴 **검색어를 지우면 원래 목록 그대로 돌아온다** — 펼침 상태도 원래대로
- [ ] 🔴 **미해소 사본 구역은 검색과 무관하게 그대로 선다**
- [ ] 🔴 **스크롤해도 검색 상자가 화면에 남는다**
- [ ] 🔴 **서버를 새로 부르지 않는다** — 이미 와 있는 값을 거른다
- [ ] 🔴 **검색어를 주소에 싣지 않는다**
- [ ] 🔴 **한글을 입력하는 중에 화면이 널뛰지 않는다**
- [ ] 🔴 **특수문자를 넣어도 안 깨진다** — 검색어를 규칙으로 다루지 않는다
- [ ] 키보드만으로 상자에 닿고 지울 수 있다
- [ ] 기존 동작이 **그대로 산다** — 카드 펼침·접힘, 드로어, 안 읽음 표시, `plan` 버튼
- [ ] `pnpm verify` green

**무엇이 남고 무엇이 사라졌나**를 붙들어라.

## 이 티켓이 하지 않는 것

- **가상 스크롤** — [02](02-the-feature-list-renders-only-what-is-on-screen.md) 다.
- **문서 본문 검색** — 캡틴이 범위를 이름과 제목으로 정하셨다([spec](../spec.md) §열린 결정).
- **정렬 바꾸기 · 다른 걸러내기 조건** — 검색 하나만이다.
- **계획 탭·단계 탭·문서 트리 검색** — 범위 밖.
- **서버 검색 · 새 API** — 값은 이미 와 있다.
- **검색어 기억하기 · 최근 검색** — 지시에 없다.

## 캡틴 확인

🔴 **캡틴이 직접 보셔야 한다.** 검색 상자가 **어디에 어떻게 서 있는가**와 **입력이 매끄러운가**는
검사가 판정하지 못한다.

- **열 곳** — gootte 의 `features` 탭.
- **할 일** — 기능 이름 일부를 넣어 보시고, 그다음 **접힌 카드 안에만 있는 티켓 제목**을
  넣어 보신다. 한글로도 넣어 보신다. 지웠다 다시 넣어 보신다.
- **보여야 할 것**
  1. 🔴 **티켓 제목으로 찾았을 때 왜 그 카드가 걸렸는지 바로 보이나** — 접힌 채로 뜨면 반쪽이다.
  2. 🔴 **한글을 칠 때 화면이 떨리지 않나.**
  3. 🔴 **검색 상자가 목록을 가리거나 어색하게 끼어 있지 않나.**
