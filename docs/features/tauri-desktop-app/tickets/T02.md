# T02 — 설정 메뉴: 감시 루트 + firstmate 홈 경로

## Goal
사용자가 감시 루트 폴더와 firstmate 홈 경로를 지정·변경·유지할 수 있는 설정 진입점을 만든다.

## Why this slice
감시 대상과 백로그 조인 원천을 사용자가 정의하게 하는 D2/D4의 데이터 계약. 이후 실시간 감시(T03)와 조인(T04)이 이 값을 소비한다.

## Scope
- core-io/core: 설정 저장소(INV-5 - 사람만 아는 값만 저장), zod contract, 결정적 read/write 함수
- backend: GET/PUT 설정 엔드포인트(기존 API 스타일 준수)
- frontend: 설정 진입점(탭 또는 헤더 기어) - 네이티브 폴더 다이얼로그는 Tauri API 호출(웹 폴백: 텍스트 입력), firstmate 홈 텍스트 입력, 저장 시 즉시 적용
- discover/read 경로가 하드코둔 값을 제거하고 설정값 소비로 전환(미설정 시 기존 기본값)

## Implementation notes
- INV-1: 파생물 아님 - 사용자가 정한 값이므로 저장 정당.
- INV-2: 여전히 관리대상 문서에는 무슨 짓도 하지 않음.
- 경로 위생: 절대 경로 정규화, 미존재 경로 저장 시 경고 표시.

## Acceptance criteria
루트 지정 → 해당 프로젝트 목록 렌더; firstmate 홈 저장; 재시작 후 유지; 잘못된 경고 표시; 기존 API/e2e 회귀 없음.

## Verification
vitest(저장소/contract) + 수동 시나리오.

## Depends on
- T01 (데스크톱 다이얼로그 UX가 자연스러운 것은 Tauri 위에서; 웹 폴백 포함하므로 병렬 가능하나 순서 권장)

## Can run in parallel with
- nothing (T03/T04가 이 설정값 소비)
