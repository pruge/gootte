# T03 — FS 이벤트 실시간 감시 (+폴링 폴백)

## Goal
지정 루트와 firstmate 홈 백로그 파일의 변화를 이벤트로 감지해 수 초 내 화면에 반영한다.

## Why this slice
INV-3(stale 금지)의 실시간성을 폴링 주기 없이 달성하는 D3 본체.

## Scope
- `src-tauri/`: notify 기반 FS 감시 명령(루트 재귀, debounce), 이벤트→프론트엔드 emit; 감시 불가 시 폴링 간격 폴백 신호
- frontend/core: 이벤트 수신 → 해당 프로젝트 리-read 트리거(기존 결정적 파서 재호출), 폴백 폴러

## Implementation notes
- 판정은 여전히 결정적(INV-4): 이벤트는 "다시 읽어라" 신호일 뿐, 해석은 기존 리더가 한다.
- 감시 대상: docs/features/**, 백로그 파일.

## Acceptance criteria
파일 추가/변경 → 수 초 내 반영(신규 feature/ticket 포함); 감시 실패 시 폴백 동작; CPU 안정.

## Verification
수동(파일 생성/수정/삭제 시나리오) + 감시 debouncer 단위 테스트.

## Depends on
- T02 (감시 루트/백로그 경로 설정값)

## Can run in parallel with
- nothing
