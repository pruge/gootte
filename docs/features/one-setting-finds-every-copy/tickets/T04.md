## Implementation notes

- 추적 제외 판정은 `git check-ignore` 로 **묻는다**. `.gitignore`·`.git/info/exclude` 를 직접
  파싱하지 않는다 — 규칙 문법이 넓고, 저장소가 이미 답을 갖고 있다.
  기능 폴더 단위로 한 번에 물어 호출 수를 줄인다.
- 미착지 판정은 `git status --porcelain` 이 그 파일을 낸다는 것으로 충분하다.
  추적 안 됨(`??`)과 고쳐짐(` M`)을 **가르지 않는다** — 캡틴께는 둘 다 "아직 안 올라간 것" 이다.
- 🔴 추적 제외이면서 미착지인 파일은 **제외가 이긴다**(안 보인다). 시안이 그 경우다.
- `git` 이 답하지 않는 사본은 표식 없이 그대로 보여준다 — 못 물었다고 문서를 감추지 않는다.

## Acceptance criteria

1. 추적 제외된 `design/*.html` 이 문서 트리에 뜨지 않는다.
2. 추적 중이지만 커밋 안 된 문서가 트리에 뜨고 미착지 표식이 붙는다.
3. 추적 안 된 새 문서도 트리에 뜨고 같은 표식이 붙는다(제외 대상이 아닌 한).
4. 착지 완료된 문서에는 표식이 없다(기존 화면 불변).
5. 표식이 어느 사본에서 왔는지는 말하지 않는다.
6. `git` 이 답하지 않는 사본의 문서는 표식 없이 그대로 보인다.
7. `pnpm -C code/web verify` green.
