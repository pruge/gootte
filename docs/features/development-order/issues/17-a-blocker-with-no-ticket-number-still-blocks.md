# 17 — 번호 없는 막힘도 막힘이다

**What to build:** 티켓이 **번호 없는 일**(아직 티켓이 없는 작업)을 기다린다고 적혀 있으면
gootte 가 그것을 **진짜 막힘으로 읽는다** — 그 문장에 숫자가 우연히 섞여 있든 없든 똑같이.
지금은 **숫자가 섞였는지에 따라 답이 갈린다.**

**Blocked by:** 🟢 **없음 — 지금 착수 가능**

**Status:** resolved (2026-08-12)

## 🔴 오늘 실제로 벌어진 일 (2026-08-11)

관리대상 jinwooauto 의 `authorship/01` 이 막혔다. 기다리는 것은 **스케줄·안전 규칙 화면 재구축**이고,
그 일에는 **아직 티켓이 없다.** 그래서 `Blocked by:` 줄에 적을 번호가 없다.

**적을 수 있는 형태가 둘뿐인데 둘 다 틀린다.**

| 적는 법 | gootte 가 읽는 것 | 실제로 벌어지는 일 |
|---|---|---|
| `없음 — …` | 막힘 없음 | 🔴 **착수 가능으로 잡혀 배차 후보에 오른다** |
| 번호 없는 산문 | 못 읽음 + **막힘 아님** | 🔴 **역시 착수 가능이고, 주황 상자까지 뜬다** |

🔴 **그날 배차 직전까지 갔다.** 캡틴이 직접 막으셨다 — 도구가 막은 것이 아니다.

## 🔴 진짜 결함 — 숫자가 섞였는지로 답이 갈린다

산문 한 줄의 운명이 **그 안에 숫자가 있느냐**로 결정된다.

| `Blocked by:` 줄 | 막히나 | 주황 상자 |
|---|---|---|
| `스케줄 표면 재구축` | 🔴 **안 막힌다** | 뜬다 |
| `스케줄 표면 재구축 (2026-07-09 계획)` | 🟢 막힌다 | 안 뜬다 |

**같은 뜻인데 날짜 하나로 갈린다.** 아무도 이걸 예측할 수 없고, 날짜를 지우는 무해한 편집 하나가
막힌 티켓을 조용히 열어 놓는다.

🟡 **지금 그 두 문서는 날짜를 넣어 우회해 두었다** — 우연에 기대고 있다는 뜻이다. 이 티켓이 그걸 없앤다.

## 🔴 이것은 11 의 결정 한 줄을 뒤집는다

[티켓 11](11-a-decorated-no-blockers-line-is-understood.md) 이 *"못 알아들은 줄이 착수 가능을
**막지 않는다**"* 를 완료 조건으로 못박았다. **그때는 옳았다.**

당시 못 알아듣던 줄의 정체는 **꾸며 쓴 "없음"**이었다 — 진짜로 막힘이 없는 티켓이었고,
막힘으로 세면 착수 가능한 것이 조용히 숨었다.

🟢 **그런데 11 이 착지하면서 그 사정이 사라졌다.** 이제 "없음" 은 꾸며도 알아듣는다.
그러고도 안 읽히는 줄이 남았다면, 그건 **사람이 진짜 막힘을 번호 없이 적은 것**이다.

| | 11 이전 | 11 착지 이후(지금) |
|---|---|---|
| 안 읽히는 줄의 정체 | 대개 꾸민 "없음" | 🔴 **번호 없는 진짜 막힘** |
| 막힘으로 세면 | 착수 가능한 것이 숨는다 | 🟢 **막힌 것이 안 나간다 — 맞다** |
| 안 세면 | 맞다 | 🔴 **막힌 것이 배차된다 — 오늘 그랬다** |

**11 을 부정하는 것이 아니라, 11 이 이룬 것 위에서 남은 경우를 다시 판정한다.**

## 🔴 그래도 조용해지면 안 된다

막힘으로 세되 **주황 상자는 그대로 둔다.** 둘 다 필요하다:

- **막는다** — 배차되면 안 되니까.
- **드러낸다** — 도구가 **언제 풀리는지 모르는** 막힘이기 때문이다. 번호가 없으면 선행이 끝나도
  자동으로 안 열린다. 🔴 **사람이 와서 풀어 줘야 하고, 주황 상자가 그 사람을 부르는 유일한 수단이다.**

지금 문구는 *"Blocked by: 를 못 읽었다"* 인데, 이제 **못 읽은 게 아니라 읽었고 번호가 없는 것**이다.
문구가 그 사실을 말해야 한다 — 아래 §문구.

## 문구

주황 상자에 이렇게 나온다(정확한 문장이 이 티켓의 산출물이다):

```
[번호 없는 막힘] jinwooauto authorship/01 — 막혀 있지만 기다리는 대상에 번호가 없다.
  선행이 끝나도 자동으로 안 열린다 — "스케줄과 안전 규칙 표면 재구축"
```

🔴 **세 가지를 다 말해야 한다** — ① 막혀 있다 ② 번호가 없다 ③ **저절로 안 풀린다.**
③ 이 빠지면 읽는 사람이 기다리면 된다고 오해한다.
🟢 사람이 쓴 원문은 **그대로 인용한다** — 요약하거나 다듬지 않는다(11 과 같은 원리).

## 완료 시 시연 가능한 것

**캡틴이 `gootte next jinwooauto` 를 친다.**

`authorship/01` 과 `access-control/07` 이 **착수 가능 목록에 없다** — 두 문서의 `Blocked by:` 줄에서
**날짜를 지워도 그대로다.**

어긋남 목록에는 그 둘이 **"번호 없는 막힘"** 으로 이름을 올린다 — 왜 저절로 안 풀리는지와 함께.

`Blocked by:` 에 **꾸민 "없음"** 을 적은 티켓은 **여전히 착수 가능**이다(11 이 지킨 것).

## 완료 조건

- [x] 🔴 **번호 없는 산문이 막힘으로 세어진다** — 그 안에 숫자가 있든 없든 같다
- [x] 🔴 **동시에 어긋남으로도 나온다** — 막았다고 조용해지지 않는다
- [x] 🔴 어긋남 문구가 **막혔다 · 번호가 없다 · 저절로 안 풀린다** 셋을 다 말한다
- [x] 🟢 **꾸민 "없음" 은 여전히 막힘 없음이다** — 11 이 고친 것이 안 되돌아간다
      (부수적으로 찾은 latent 결함도 같이 고쳤다 — `**없음**`·`(없음)` 처럼 닫는 꾸밈이
      바로 붙은 형태를 isNoDeps 가 못 알아보던 것)
- [x] 🟢 **번호로 적힌 진짜 막힘은 그대로다** — 선행이 다 끝나면 열린다
- [x] 번호와 산문이 **한 줄에 섞여** 있으면 번호를 읽는다(지금 동작 유지) —
      번호 뒤 사유를 항목으로 잘못 갈라 헛된 막힘을 만들지 않는다
- [x] 🔴 **판정 자리가 하나다** — 화면 · 터미널 · 서버가 같은 답을 낸다(11 과 같은 조건)
- [x] `features` 탭의 막힘 표시가 안 깨졌다

## 테스트

| 무엇 | 어디 | 첫 커버인가 |
|---|---|---|
| 🔴 **숫자 없는 산문**이 막힘으로 세어진다 | `core` 단위 | 🔴 **예** |
| 🔴 **같은 문장에 날짜만 더해도 답이 같다** | `core` 단위 | 🔴 **예 — 이 결함의 본체다** |
| 막혔으면서 동시에 어긋남으로도 나온다 | `core` 단위 | 🔴 **예** |
| 꾸민 "없음" 은 막힘 없음이다 | `core` 단위 | 🟢 있음(11) — **유지되는지 확인** |
| 번호 막힘이 선행 완료로 열린다 | `core` 단위 | 🟢 있음 — 유지 |
| 번호 + 사유가 한 줄에 섞인 실제 서식 | `core` 단위 | 🟢 있음 — 유지 |

🔴 **11 의 검사를 지우거나 고쳐 쓰지 마라.** 그중 하나(*"못 알아들은 줄이 착수 가능을 막지 않는다"*)만
이 티켓이 뒤집는다 — **그 검사 하나를 반대 방향으로 다시 쓰고, 왜 뒤집혔는지를 검사 이름에 남긴다.**
나머지는 그대로 통과해야 한다.

## 이 티켓이 하지 않는 것

- **관리대상 문서 수정** — gootte 는 관리대상에 안 쓴다(INV-2). 고치는 것은 읽는 쪽이다.
  🟡 두 문서에 넣어 둔 날짜 우회는 **이 티켓이 착지한 뒤 사람이 걷어낸다** — 여기서 건드리지 않는다.
- **`Blocked by:` 표기법을 새로 정하는 일** — 🔴 **번호 없는 막힘을 적는 새 문법을 만들지 마라.**
  사람이 쓰던 대로 쓰고 기계가 맞춘다(11 과 같은 원칙).
- **번호 없는 막힘을 대신 만들어 주는 일** — 티켓을 새로 파거나 번호를 지어내지 않는다.
  그건 사람이 정한다.
- **막힘을 저장소에 적는 일** — 막힘의 근거는 티켓 문서다(사양 §범위 밖).
- **계획 탭 겉모습** — 어긋남 상자의 생김새는 안 건드린다. 문구만 바뀐다.

## 캡틴 확인

- **어디서** — 터미널에서 `gootte next jinwooauto`, 그리고 gootte 의 `plan` 탭.
- **무엇을** — 착수 가능 목록에 `authorship/01` 이 **없는지** 본다.
  그다음 어긋남 목록의 **"번호 없는 막힘"** 줄을 읽어 본다.
- **무엇이 보여야 하나**
  1. 🔴 **막힌 것이 배차 후보에 안 뜬다** — 오늘 뜬 것이 안 뜬다.
  2. 🔴 **그 줄을 읽고 "내가 뭘 해야 하는지" 가 바로 잡히나** — 저절로 안 풀린다는 것이
     읽히지 않으면 문구가 덜 된 것이다.
  3. 오늘처럼 **멀쩡한 티켓에 헛된 주황색이 뜨지 않나.**
