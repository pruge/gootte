# 13 — 의견 물어보기를 걷어낸다

**What to build:** 티켓 06 이 만든 **의견 요청 일체를 없앤다** — `plan` 탭 맨 위의 상자,
버튼, 저장 표, 터미널 명령, 그리고 그것을 위한 계산까지. 지워지고 나면 `plan` 탭 맨 위에는
**캡틴이 정작 보셔야 할 것**이 온다.

**Blocked by:** 없음 — 지금 착수 가능

**Status:** ready-for-agent

## 캡틴 지시 (2026-08-11, 원문)

> "의견 물어보기는 뭐야? 어제 내가 필요할때 적고 보내야하는데. 네가 묻고 싶은것을 넣는거야?"

> "아니 저게 왜 필요해? 나한테 무슨 의미가 있어?"

> "저게 맨 위에 있으면 정작 봐야할 내용이 뒤로 밀리잖아. **아예 없애.**"

## 🔴 왜 없애나 — 요청을 거꾸로 만들었다

06 의 출발점은 캡틴의 이 말이었다:

> "그때는 **네가 자동으로 인지하여 의견을 말했으면** 한다.
> background에서 넘겨주는 방식도 괜찮고. 아니면 버튼을 두어 네게 알리도록해도 좋고."

**planner 가 알아채고 planner 가 말한다** — 그것이 요청이었고, 버튼은 나르는 방법 중 하나였다.
만들어진 것은 반대다:

| 캡틴이 요청하신 것 | 만들어진 것 |
|---|---|
| planner 가 알아채서 **말해 준다** | 캡틴이 상자를 발견하고 **누르러 가신다** |
| 캡틴은 아무것도 안 하신다 | 누를지 판단하고, 기다리고, 화면으로 **돌아와 확인**하신다 |

그리고 캡틴과 planner 는 **이미 대화 창에서 이야기한다.** 거기서는 맥락 전부를 갖고 몇 초 만에
답이 오간다. 이 화면은 그것의 **느리고 얇은 판본**이다 — 한 줄짜리 물음, 분 단위 왕복,
다른 화면에 놓인 답. 🔴 **더 나은 통로가 이미 있는데 못한 통로를 화면 맨 위에 세운 것**이 결함이다.

**대가는 자리다.** 저 상자가 맨 위에 있으면 계획 자체가 아래로 밀린다.
`plan` 탭은 순서를 보는 화면이지 planner 와 편지를 주고받는 화면이 아니다.

## 🔴 알아채는 계산까지 없앤다

캡틴이 **"아예 없애"** 라고 하셨다. 상자만 지우고 계산을 남겨 두면
**아무도 안 쓰는 코드와 아무도 안 읽는 표**가 남아, 다음 사람이 그것을 되살릴 근거로 삼는다.

🟢 되살리기는 언제든 싸다 — 이 티켓과 06 이 이유를 그대로 갖고 있다.
필요해지면 **그때 캡틴이 원래 원하신 모양(planner 가 먼저 말을 건다)으로** 새로 쓴다.

## 지울 것

| 화면 | 의견 요청 상자 하나(패널 컴포넌트), 그리고 그것을 부르는 자리 |
| 서버 | 의견 요청을 받고 내주는 경로 |
| 저장 | `opinion_request` 표와 그 저장 코드 |

🔴 **`extra` 를 건드리지 마라.** `ask` 와 `extra` 는 firstmate 를 깨우는 **같은 규약**을 쓰지만
서로 다른 물건이다. `ask` 가 사라져도 **`extra` 는 그대로 동작해야 하고**,
firstmate 의 확인 장치가 여전히 `extra` 로 깨어나야 한다.

🔴 **드래그의 네 검사(티켓 04)도 건드리지 마라.** 그것은 기계가 아는 사실을 그 자리에서
알려주는 것이고 캡틴이 없애라고 하신 것이 아니다.

🔴 **`next` · 어긋남 · 드래그 · 단계·순위 계산은 하나도 안 바뀐다.** 이 티켓은 **빼기만** 한다.

## 사양도 같이 고친다

사양(`spec.md`)에서 의견 요청을 설명하는 절, 저장 표 목록의 한 줄, 명령 목록의 세 줄,
화면 설명의 해당 대목을 걷어내고, **없앤 이유와 캡틴 지시를 남긴다.**
🔴 **06 티켓 파일은 지우지 마라** — 착지한 기록이고, 왜 되돌렸는지가 거기 있어야 한다.
맨 위에 13 이 걷어냈다는 줄만 붙인다.

## 완료 시 시연 가능한 것

캡틴이 `plan` 탭을 연다. **맨 위에 의견 요청 상자가 없다.**
순서를 아무리 끌어 바꿔도 그 상자가 다시 나타나지 않는다.
`gootte ask` 는 이제 없는 명령이고, 사용법에도 안 나온다.
`gootte extra` 는 그대로 동작하고, firstmate 는 여전히 `extra` 로 깨어난다.
