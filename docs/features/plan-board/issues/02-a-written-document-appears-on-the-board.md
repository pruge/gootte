# 02 — 문서를 쓰면 판에 저절로 나타난다

**What to build:** 관리대상에 기능 문서를 하나 쓰면, 아무에게도 알리지 않았는데 `plan` 탭
**대기 칸에 카드가 나타난다.** 판은 캡틴의 그림대로 위에 **작업 대상** 하나, 아래에
**대기 · 예약 · 폐기 · 완료** 네 탭을 가진 칸 하나로 그려진다.

**Blocked by:** 01 — 옛 트랙·순위·어긋남이 살아 있는 동안에는 같은 화면에 두 모델이 겹친다

**Status:** resolved (2026-08-12)

## 이 티켓이 없애는 문제

캡틴의 문제점 ① — "문서를 써도 planner 가 gootte 에 등록하지 않는다".
등록이라는 행위를 **없애서** 없앤다. 자리 행이 없는 기능은 전부 대기다.
빠뜨릴 수 있는 절차가 존재하지 않는다(INV-B1).

## 만드는 것

**저장소** — 표 둘(spec §저장 형태). 옛 표는 01 이 이미 지웠으므로 새로 만든다.
`placement` 행이 없다는 것이 대기라는 뜻이며, 대기를 뜻하는 값을 `area` 에 두지 않는다.
값으로 두면 "행 없음"과 "값이 대기"라는 같은 뜻의 두 표현이 생기고, 둘이 갈라진다.

**판정** — `core` 의 순수 함수 한 벌이 기능 목록과 자리 행을 받아 다섯 칸으로 나눈다.
화면도 CLI 도 이 함수만 쓴다(spec §판정 자리는 하나뿐).

**화면** — 캡틴 그림 그대로. 작업 대상 칸이 위, 네 탭 칸이 아래.
카드는 기능 제목과 그 아래 티켓 줄들을 보여준다. 이 티켓에서는 **읽기만** 한다 —
끌어 옮기는 것은 03, 체크상자와 접힘은 04.

문서가 바뀌면 화면이 저절로 다시 그려진다 — 실시간 배선은 이미 있다(spec F1·F3).
이 티켓은 그 배선에 **얹기만** 하고 새 감시를 만들지 않는다.

## 완료됐을 때 보여줄 수 있는 것

캡틴이 `plan` 탭을 연 채로 둔다. 다른 창에서 관리대상에 새 기능 폴더와 `spec.md` 를 만든다.
**탭을 새로 고치지 않았는데** 대기 칸에 그 기능의 카드가 나타난다.
카드 안에는 그 기능의 티켓들이 줄로 보인다.

## 인수 기준

- [x] 자리 행이 없는 기능은 대기 칸에 보인다.
- [x] 관리대상에 기능 문서를 새로 쓰면, 새로 고침 없이 대기 칸에 나타난다.
- [x] 기능 문서를 지우면 카드가 사라진다.
- [x] 다섯 칸이 캡틴 그림의 배치대로 그려지고, 아래 네 칸은 탭으로 전환된다.
- [x] 어느 칸도 gootte 가 관리대상에 무언가를 쓰지 않는다(INV-2).
- [x] 카드가 보여주는 티켓 제목·개수는 문서에서 온 것이고 저장된 사본이 아니다(INV-5).

## 테스트

- 다섯 칸 나누기는 `core` 순수 함수 단위 테스트로 덮는다 — 🔴 이 티켓이 **처음** 덮는 코드다.
  자리 행 없음 → 대기, 각 `area` 값 → 해당 칸, 이 둘이 최소 골격이다.
- 저장소 읽기·쓰기는 `core-io` 테스트. 01 이 옛 테스트를 지웠으므로 자리를 새로 쓴다.
- 화면은 `frontend` 테스트로 다섯 칸이 그려지는 것과 카드가 대기에 뜨는 것까지.

## 이 티켓이 하지 않는 것

- 카드를 끌어 옮기지 않는다(03).
- 체크상자·완료 판정·접힘을 만들지 않는다(04).
- 단계를 그리지 않는다(05).

## 실행 등급

**기본 등급 위.** 이유는 파일이 많아서가 아니라, **자리 모델의 모양이 실제 소비자를 붙여 봐야 정해지기
때문이다.** 계약 타입·저장소·서버·화면이 같은 한 모델을 동시에 만족해야 하고, 어느 한 층에서
모양을 바꾸면 나머지 셋이 함께 움직인다. 계획 단계에서 닫지 못한 것은 "행 없음 = 대기"가
읽는 쪽 네 군데에서 전부 자연스럽게 읽히는가이며, 그것은 붙여 봐야 안다.

## 캡틴 확인

- **열 곳** — gootte 를 켜고 `plan` 탭.
- **할 일** — 탭을 연 채로, 다른 창에서 관리대상 프로젝트에 기능 폴더 하나와 `spec.md` 를 만든다.
- **보여야 할 것** — 새로 고치지 않았는데 대기 칸에 그 카드가 나타난다.
  그리고 판의 배치가 캡틴이 그리신 모양대로다.
