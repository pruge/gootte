# 03 — 캡틴이 카드를 옮긴다

**What to build:** 대기 칸의 카드를 **끌어서 작업 대상에 놓는다.** 여러 장 한꺼번에도 된다.
작업 대상의 카드를 예약·폐기·완료로 내릴 수 있다. 끌기 말고도, **카드 머리의 아이콘 둘**로
문서를 열거나 어느 칸으로 보낼지 물어보는 대화상자를 띄운다.

**Blocked by:** 02 — 옮길 판과 옮겨 담을 자리가 먼저 있어야 한다

**Status:** resolved (2026-08-12)

## 만드는 것

**끌어 놓기** — 칸 사이, 그리고 작업 대상 안에서의 카드 순서 바꾸기.
여러 장 선택해서 한 번에 옮기는 것을 포함한다(캡틴 제안 2 "여러개 가능").

🔴 **놓을 때 검사하지 않는다.** 옛 판에는 드래그마다 네 가지 경고가 있었고 01 이 걷어냈다.
되살리지 않는다(INV-B3). 캡틴이 놓은 자리가 곧 정답이다.

**카드 머리 아이콘 둘**

| | 무엇을 하나 |
|---|---|
| 문서 아이콘 | `features` 탭의 그 기능 문서로 간다 — 기존 통로를 그대로 쓴다. 두 번째 문서 보기를 짓지 않는다 |
| 이동 아이콘 | "어느 칸으로 보낼까요" 대화상자. 지금 있는 칸은 고를 수 없다 |

이동 대화상자는 끌기의 **대체 경로**다. 카드가 많아 끌기 힘들 때와, 완료 칸의 접힌 카드를
다시 꺼낼 때 쓰인다.

**완료 칸으로 직접 옮기기** — 남은 티켓이 있어도 캡틴은 카드를 완료로 보낼 수 있다.
그 순간 `closed_at` 이 찍힌다. 🔴 **이유를 묻지 않는다**(캡틴 결정) — 왜 남기고 닫았는지는
그 티켓 문서에 적히고, 문서 아이콘이 그리로 가는 길이다.

**작업 대상을 떠나면 단계가 지워진다** — 예약·폐기·완료 어느 쪽이든, 그 기능 티켓들의 단계 행을
지운다. 단계는 작업 대상에 있는 동안만 존재하는 값이다(spec §단계는 잠시 붙었다 사라지는 것이다).

**작업 대상으로 올리면 9999 단계로 붙는다** — 그 기능의 티켓 전부. 맨 뒤에 쌓여 눈에 띄고,
firstmate 가 진짜 번호를 매기면 사라진다(캡틴 결정, spec §올라온 카드는 9999 단계로 붙는다).

🔴 **옛 숫자를 되살리지 않는다** — 되올린 카드도 9999 에서 다시 시작한다.
되살리면 아무도 아직 맞는지 확인하지 않은 낡은 계획이 새 계획인 척한다.

## 완료됐을 때 보여줄 수 있는 것

캡틴이 대기 칸에서 카드 두 장을 골라 작업 대상으로 끌어 놓는다. 두 장이 올라간다.
한 장을 예약으로 내린다. 작업 대상에서 사라진다. 다시 올린다. 원래 자리로 돌아온다.
카드 머리의 문서 아이콘을 누르면 그 기능 문서가 열린다.

## 인수 기준

- [x] 대기 → 작업 대상 끌어 놓기가 되고, 새로 고쳐도 그대로다.
- [x] 여러 장을 한 번에 옮길 수 있다.
- [x] 작업 대상 안에서 카드 순서를 바꿀 수 있다.
- [x] 작업 대상 → 예약·폐기·완료로 내릴 수 있고, 예약·폐기는 단계 화면에서 빠진다.
- [x] 작업 대상을 떠나면 그 기능 티켓들의 단계가 지워진다.
- [x] 작업 대상으로 올리면 그 기능 티켓들이 9999 단계로 붙는다 — 되올린 것도 옛 숫자가 아니라 9999 다.
- [x] 남은 티켓이 있는 카드를 완료로 옮길 수 있고, 이유를 묻는 입력창이 **뜨지 않는다.**
- [x] 카드 머리 아이콘 둘이 각각 문서 열기와 이동 대화상자로 동작한다.
- [x] 놓는 순간 어떤 경고도 뜨지 않는다.

## 테스트

- 자리·순서 변경 저장은 `core-io` 테스트.
- 옮긴 뒤의 칸 나누기 결과는 02 가 세운 순수 함수 테스트를 그대로 늘려 쓴다 — 두 번째 판정 자리를 만들지 않는다.
- 화면은 `frontend` 테스트로 대화상자와 아이콘 동작까지. 끌기 자체는 캡틴 확인이 맡는다.

## 이 티켓이 하지 않는다

- 체크상자·자동 완료·접힘(04).
- 단계 매기기와 `next`(05).
- 이동 이력을 남기지 않는다 — 덮어쓰기뿐이다.

## 캡틴 확인

- **할 일** — 대기 칸에서 카드 두 장을 작업 대상으로 끌어 놓고, 한 장을 예약으로 내렸다가 다시 올린다.
  카드 머리의 아이콘 둘을 눌러 본다.

  놓을 때 아무 경고도 뜨지 않는가.
