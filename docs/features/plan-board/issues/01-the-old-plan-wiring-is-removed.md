# 01 — 옛 계획 배선을 걷어낸다

**What to build:** 어긋남·트랙·순위·왜·드래그 경고, 그리고 아무도 안 읽는 표 둘을 **코드에서 지운다.**
`plan` 탭은 이 티켓이 끝나면 "새 판을 짓는 중" 한 줄만 남는다. 02 가 그 자리에 새 판을 세운다.

**Blocked by:** 🟢 **없음 — 지금 착수 가능**

**Status:** claimed

## 왜 먼저 걷어내나

옛 개념(트랙·순위·왜 닻·어긋남)이 남은 채로 새 자리 모델을 얹으면, 두 모델이 한동안 공존하며
**같은 화면에서 서로를 설명하려 든다.** 캡틴이 "기존 배선 싹 걷어내고 새로 작업해"라고 하신 이유다.
이 티켓은 되돌리기 쉽고(순수 삭제) 다른 넷을 전부 가볍게 만든다.

## 지우는 것

| 무엇 | 왜 |
|---|---|
| 어긋남 6종 — 계약 타입, 계산, 목록 화면 | spec §문제 — 흉터였다. 원인을 없애므로 셀 것이 없다 |
| 드래그 4검사와 그 배너 | 같은 가족이다. 새 판은 자리 이동을 검사하지 않는다 |
| 트랙 — 저장 칸, 묶기, 이름 바꾸기 화면 | 다섯 자리가 대신한다 |
| 순위(실수) | 작업 대상 안의 카드 순서로 대체된다(02) |
| `왜` 와 왜 닻 셋 | 이유는 문서가 갖는다. 계획 DB 는 이유를 담지 않는다 |
| `opinion_request` 표 | 읽는 코드가 없다. 안에 갇힌 질문 1건은 아래 §갇힌 질문 참조 |
| `extra` 큐 | 지금 판에 자리가 없다. 필요해지면 별도 기능으로 다시 판다 |
| `history.md` 기록 | 계산에 쓰이지 않는다. 닫힘 시각은 02 의 표가 갖는다 |
| 옛 CLI 명령 `set` · `set-feature` · `drop` · `order` · `extra` | 05 가 `step` · `board` 를 세운다 |

`next` 명령과 그 계산은 **자리만 비워 둔다** — 05 가 새 규칙으로 다시 쓴다.
이 티켓이 끝난 시점의 `next` 는 "아직 없다"고 말하고 끝난다.

🔴 `discover` 와 `db migrate` 는 건드리지 않는다.

**`AGENTS.md` 의 명령 표에서 지운 명령을 빼라.** 표에 남겨 두면 다음 사람이 있는 명령으로 읽고
치다가 실패한다 — 문서가 코드보다 오래 사는 자리다.

## 갇힌 질문 하나 — 캡틴이 버리기로 하셨다 (2026-08-12)

실물 DB `opinion_request` 표에 답 없는 질문 1건이 있었다(2026-08-11 등록). 이 표를 읽는 코드가
저장소에 한 줄도 없어 캡틴께 닿은 적이 없었다. **원문을 캡틴께 전했고, 버리라고 하셨다.**
표와 함께 지운다. 옮겨 담을 자리를 만들지 않는다.

## 완료됐을 때 보여줄 수 있는 것

캡틴이 `plan` 탭을 연다. 트랙도, 어긋남 상자도, 경고 배너도 없다.
"새 판을 짓는 중" 한 줄이 있다. 다른 탭(`features`)은 **하나도 달라지지 않는다.**

## 인수 기준

- [ ] 어긋남 관련 타입·계산·화면이 저장소에서 사라진다. `Mismatch` 로 검색해 나오는 것이 없다.
- [ ] 드래그 경고 관련 타입·계산·화면이 사라진다.
- [ ] 계획 DB 에서 트랙·순위·왜·왜 닻 칸이 사라지고, `opinion_request`·`extra` 표를 만드는 코드가 사라진다.
- [ ] `history.md` 를 쓰는 코드가 사라진다.
- [ ] `set` · `set-feature` · `drop` · `order` · `extra` 명령이 사라지고, `AGENTS.md` 의 명령 표에서도 빠진다.
- [ ] `discover` 와 `db migrate` 는 그대로 동작한다.
- [ ] `features` 탭의 동작이 하나도 바뀌지 않는다.

## 테스트

- 지워진 것의 테스트도 함께 지운다 — 남겨 두면 다음 사람이 되살릴 근거로 읽는다.
- `features` 탭과 문서 파싱 테스트는 **한 줄도 고치지 않는다.** 고쳐야 한다면 이 티켓의 범위를 넘은 것이다.

## 이 티켓이 하지 않는 것

- 새 자리 모델을 만들지 않는다(02).
- `next` 를 다시 쓰지 않는다(05).
- 옛 DB 데이터를 옮기지 않는다 — 버린다.
