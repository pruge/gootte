# T01 — watchRoots 명시 목록으로 감시 뿌리 교체

Time: started=2026-08-30T00:00:00+09:00 finished=2026-08-30T00:00:00+09:00

## Goal

`Settings.firstmateHome` 하나에서 자동 파생하던 감시 뿌리를, 사용자가 명시적으로 추가하는
`watchRoots: string[]` 목록으로 교체한다. 목록에서 폴더를 빼면 그 폴더(와 treehouse 사본)는
더 이상 감시되지 않는다.

## Why this slice

firstmate 가 토큰을 무지막지하게 먹어 사용을 금지했으니, gootte 가 firstmate 구조에 종속된
자동 파생을 계속 쓰는 것은 맞지 않다. 감시 대상을 사람이 직접 고르는 것이 제품의 핵심
("다음 무엇 / 지금 누가" 를 한 화면에서)과 충돌하지 않는 유일한 형태다.

## Produces

- `contract` `Settings.watchRoots`, `SettingsResponse.effectiveWatchRoots`, `SettingsUpdateRequest.watchRoots`
- `core-io` `settingsHasWatchRoots(file)`, `resolveWatchRoots(dataDir, fallbackRoots)`, raw 라운드트립 `writeSettings`
- `backend` `effectiveRoots` → `resolveWatchRoots`, PUT `watchRoots` 정규화 + `onWatchRootsChange`, `server.ts` 감시기 재바인딩
- `frontend` `SettingsDialog` 감시 폴더 목록 에디터(추가/삭제), `effectiveWatchRoots` 프리필

## Consumers
