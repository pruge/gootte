## Goal

T01~T07 이 끝난 앱을 **ego-browser 로 실제 클릭해** 캡틴이 겪던 증상이 사라졌는지 확인하고,

## Why this slice

앞 일곱 장의 검증은 전부 `pnpm verify`(단위·계약)와 측정이다. 🔴 **그중 어느 것도 "클릭하면
바로 읽힌다" 를 사람이 겪는 방식으로 확인하지 않는다.** 캡틴이 신고한 것은 화면에서 겪은 지연이고,
그 자리에서 사라졌는지 보는 것이 이 기능의 완료 조건이다. 통과했다는 보고는 **실제로 클릭해 본
뒤에만** 할 수 있다.

**AC3 — 300ms 를 넘긴 이유는 백엔드가 아니다**

브라우저에서 문서 API 만 따로 재니 **3~5ms**(18,320자)다. 클릭→표시의 311~331ms 는 전부
**클라이언트의 마크다운 렌더**다. 백엔드 읽기 경로는 이 기능의 목표를 넘겼고, 남은 것은
프론트엔드 렌더링이다 — 🔴 **이 기능의 범위 밖이라 고치지 않았다. 별건으로 볼 값어치가 있다.**
(같은 클릭이라도 작은 문서는 42ms 였다 — 크기에 비례한다는 증거다.)

**AC4 — 실제로 만들어 보고 지웠다**

`jinwooauto/.claude/worktrees/fsm-coordination-docs` 안에 **커밋하지 않은** `T99.md` 를 만들었더니
4초 안에 API 와 화면에 나타났고(제목 "read-path-redesign T08 검증용 임시 티켓"), 지우니 사라졌다.
🔴 이것이 캡틴이 물었던 구멍이다 — T05 전에는 커밋 전까지 어느 경로로도 안 잡혔다.

**AC6 — 못 본 것을 봤다고 적지 않는다**

- **갈라짐**: 지금 jinwooauto 의 사본들은 문서가 갈려 있지 않아 배지가 뜰 조건 자체가 없었다.
- **추적 제외**: 두 프로젝트 모두 `docs/features` 아래에 gitignore 된 파일이 **하나도 없다**
  (gootte 0개 · jinwooauto 의 html 6개는 전부 추적 중이라 트리에 그대로 떠야 하고, 실제로 6개 다 떴다).

둘 다 **단위 테스트가 덮는다**(`features.test.ts` 의 추적 제외 묶음 · `.md 아닌 파일도 갈라짐으로
잡힌다`). 화면에서 확인하지 못했다는 사실을 그대로 남긴다.

**AC7 — 관리대상 워킹트리**

## Implementation notes

- ego-browser 는 `ego-browser nodejs <<'EOF' ... EOF` 히어독으로 쓴다. 파일로 쓰지 않는다.
- 태스크 스페이스를 한 번 만들고 라운드마다 `useOrCreateTaskSpace(task.id)` 로 재사용한다.
- 시간 측정은 브라우저 안에서 한다 — 클릭 직후부터 드로어에 본문이 나타날 때까지를
  `performance.now()` 로 재고 `cliLog` 로 낸다. 🔴 **눈대중으로 "빨라졌다" 고 적지 마라.**
- "앱 켜고 처음"(AC2)은 **서버를 새로 띄운 직후 첫 클릭**이어야 한다 — 캐시가 데워진 뒤 재면
  재는 의미가 없다.
- 관리대상이 클수록 증상이 잘 드러난다 — jinwooauto(사본 4개 · 기능 61 · 티켓 238)로 확인한다.
  gootte 만 보고 통과시키지 않는다(354ms 라 원래 안 느리다).

## Acceptance criteria

- AC1 — **서버를 막 띄운 직후** jinwooauto 를 열고 문서를 클릭했을 때 본문이 **1초 이내**에 뜬다.
- AC2 — 그 첫 클릭이 목록 계산을 기다리지 않는다(T07 AC1·AC2 의 사람 손 재확인).
- AC3 — 이미 열어 본 프로젝트에서 문서 클릭이 **300ms 이내**에 뜬다.
- AC4 — worktree 안에 **커밋 안 된 새 티켓 파일**을 만들면 화면에 나타난다(T05 AC2 의 재확인).
- AC5 — 네 탭(memo · features · plan · steps)이 전부 뜨고, 기능 카드·티켓 행·문서 트리가 그려진다.
- AC6 — 갈라짐 배지·추적 제외 숨김이 살아 있다(T06 회귀 가드의 사람 손 재확인).
- AC7 — 검증 뒤 관리대상 저장소 워킹트리에 gootte 가 쓴 흔적이 없다(INV-2).
- AC8 — 모든 측정값과 스크린샷이 `## Comments` 에 적혀 있고, 미달 항목은 미달로 적혀 있다.
