# T02 — 목록 계산이 `.md` 아닌 파일의 본문을 읽지 않는다

**Blocked by:** 없음 — 즉시 착수 가능

**Time:** started=2026-09-04T11:35:23+09:00 finished=2026-09-04T11:41:06+09:00

## Goal

`walkSlug` 가 기능 폴더의 **모든 파일 바이트**를 문자열로 올리는 것을 멈추고, 파싱이 필요한
`.md` 본문만 읽는다. 나머지는 트리에 **이름만** 싣는다.

## Why this slice

측정에서 사본 4개 × 1,450 파일 × 22MB 를 매 계산마다 읽는다. 그중 파싱 대상은 `.md` 386개뿐이고,
나머지는 `.html` 6개 · **100KB 넘는 `.log` 5개** · `.py` 1개다. 트리에 필요한 것은 이름·종류이지
내용이 아니다. 구조를 안 바꾸고 입력 크기를 줄인다.

## Produces

`.md` 본문만 담은 `files` 맵. 트리(`FeatureDocNode`)는 지금과 같은 모양·같은 항목.

## Consumers

T04(기능 폴더 단위 캐시) — 캐시할 값이 작아야 폴더 단위 보관이 싸다.

## Touched surfaces

`core-io/src/features.ts` (`walkSlug` · `mergeSlug` · `resolveFile` 주변)

## Explicitly out of scope

- 트리에서 파일을 **숨기지 않는다** — 목록은 지금과 똑같이 전부 보인다(INV-4: 실재하는 것만, 그러나 전부).
- 드로어의 원문 읽기 — 그쪽은 `readFeatureDoc` 이 요청 시 파일 하나를 직접 읽으므로 이 변경과 무관하다.
  `.log`·`.html` 도 드로어에서는 **그대로 열려야 한다.**

## Locked decisions

없음 — spec §7 W1 의 기계적 정리다.

## Evidence anchors

- `core-io/src/features.ts:53` `walkSlug` — 확장자를 가리지 않고 `read(abs)` 한다.
- `spec.md` §3 — 파일 구성 실측(386 md / 6 html / 5 log(100KB+) / 1 py).

## Regression guards

- 🔴 **여러 사본 합집합·`Time:` 정방향 병합이 그대로다** — `core-io/src/features.test.ts` 의
  "여러 사본 합집합 + 나중 판(T02)" · "여러 사본 Time: 정방향 병합(T05)" 묶음이 전부 통과해야 한다.
- 🔴 **갈라짐(`conflict`) 판정이 약해지지 않는다** — `.md` 가 아닌 파일이 사본마다 달라도 지금은
  갈라짐으로 잡히는지 먼저 확인하고, 잡힌다면 그 판정을 유지할 방법(내용 대신 크기·해시)을 함께 넣는다.
  🔴 **확인 없이 "안 잡혔겠지" 로 넘어가지 마라.**
- 🔴 드로어에서 `.log`·`.html` 원문이 그대로 열린다.

## Scope

1. `walkSlug` 에 "본문을 읽을 파일" 판정을 넣는다 — `.md` 만.
2. `.md` 아닌 파일도 **트리에는 그대로** 들어간다(`buildDocTree` 는 이미 내용을 안 읽는다 — 손대지 않는다).
3. `resolveFile`/갈라짐 판정이 내용 없는 파일을 만났을 때의 행동을 명시한다(위 Regression guards 참고).

## Implementation notes

- `buildDocTree` 는 이미 listing 만 한다(`features.ts:72` 주석) — 이 티켓은 `walkSlug` 쪽만 건드린다.
- 확장자 목록을 늘리고 싶어지면 멈추고 물어라. 파싱하는 것은 `.md` 뿐이다(`parseFeatureSpec`·`parseTicket`·`parseNewTicket`).

## Acceptance criteria

- AC1 — `walkSlug` 가 `.md` 아닌 파일을 `readFileSync` 하지 않는다.
- AC2 — 문서 트리에 뜨는 항목이 변경 전과 **완전히 같다**(이름·순서·종류).
- AC3 — 드로어에서 `.log`·`.html` 원문이 그대로 열린다.
- AC4 — 합집합·`Time:` 병합·갈라짐 관련 기존 테스트가 전부 통과한다.
- AC5 — jinwooauto 기준 `readFeatures` 실측이 줄었고 그 수치를 spec 에 적었다.

### 2026-09-04 — 완료. 가드가 요구한 확인을 했고, 절충 없이 둘 다 지켰다.

**🔴 가드가 요구한 확인부터 — `.md` 아닌 파일도 지금 갈라짐으로 잡힌다**

티켓이 *"확인 없이 «안 잡혔겠지» 로 넘어가지 마라"* 고 했으므로 실제로 재현했다: 임시 저장소 두 벌에
`design/x.html` 을 서로 다르게 두면 **오늘도 `conflict` 에 실린다.** 그래서 본문을 안 읽는 것만으로는
안 되고, 비교 토큰이 필요했다.

**한 일**

- `walkSlug` 이 `.md` 는 본문을, **그 외는 sha1 해시만** 싣는다(`fileDigest`). `CopySlug.digests` 신설.
- `mergeSlug` 이 `.md` 아닌 경로에도 **같은 `resolveFile` 절차**를 해시로 돌린다. 고른 "내용"(= 해시)은
  버린다 — `contentByPath` 는 `spec.md`·`issues/*.md`·`tickets/T*.md` 만 조회하므로 해시가 파서에
  닿을 길이 없다.
- 회귀 추가: `🔴 .md 아닌 파일도 갈라짐으로 잡힌다` — 두 사본이 같은 `.html` 을 서로 다르게 커밋해
  갈라짐이 뜨는지, 트리에는 그대로 뜨는지 함께 본다.

**대안 비교 (실측, 사본 3개 · `.md` 1,028개 / 그 외 30개)**

| 안 | 시간 | 갈라짐 판정 |
|---|---|---|
| 지금(전부 utf8 문자열) | 205ms | 유지 |
| **`.md` 만 utf8 + 나머지 Buffer+해시** ← 채택 | **60ms** | **유지** |
| `.md` 만 utf8 + 나머지 size 만 | 57ms | ⚠️ 같은 크기면 못 잡음 |

size-only 와 시간 차이가 3ms 뿐이라 **판정을 약화시킬 이유가 없었다.** 티켓이 예상한 절충이
실측에서는 필요 없었다.
