# T06 — slug 범위 완료 판정 (번호 충돌 버그 수정)
Time: started=2026-08-29T08:33:40+09:00 finished=2026-08-29T08:56:43+09:00

## Goal

git 리졸버의 `T<NN>` 매칭에 **feature slug 범위**를 추가해
다른 기능의 같은 번호 티켓이 오탐 완료되는 버그를 수정한다.

## Bug

현재 `ticket-git-status.ts`의 done 캐시는 `done[repo][num]` 구조:

```ts
const TICKET_TOKEN = /\bT(\d{1,3})\b/gi;
// → done["gootte"]["01"] = true
```

`T01`이 커밋 메시지 어디에든 나오면 **모든 기능의** T01이 완료로 찍힌다.
기획 문서 커밋 제목("tickets T01-T03"), 교차 참조, 다른 기능의 구현 커밋 전부가 오탐 원천.

실측: `T01`이 42개 커밋, `T02`가 27개, `T03`이 17개 — 대부분 다른 기능 소속.
ticket-time-stamp T01~T03이 코드 한 줄 없이 전부 "done"으로 표시됨.

## Root cause

grill D3("커밋↔티켓 연결 규칙")가 `T<NN>` 토큰만으로 매칭하고 slug을 안 본다.
캡틴 커밋 스타일이 `feat(ticket-done-from-git): T01 ...`처럼 slug을 이미 쓰고 있으므로
slug 연관을 활용하면 된다.

## Produces

- `done[repo][slug][num]` 구조로 변경 — slug별 격리.
- 매칭 규칙: 커밋 메시지에 slug(또는 slug의 고유 부분)과 `T<NN>`이 **같이** 나올 때만 완료.
  예: `feat(ticket-done-from-git): T01 ...` → `ticket-done-from-git/01 = done`.
  slug 없이 `T01`만 나오는 커밋은 무시(안전 쪽 오류: 미완료로 남김).
- 캐시 버전 올림 (v1 → v2; 기존 캐시 자동 무효화).
- `resolveTicketDone(repo, slug, num)` — 이미 slug 인자를 받고 있으나 안 쓰고 있음. 이제 씀.

## Touched surfaces

- `code/web/core-io/src/ticket-git-status.ts` — 매칭 로직 + 캐시 구조 변경
- `code/web/core-io/src/ticket-git-status.test.ts` — 교차 기능 오탐 회귀 시험 추가
- `code/web/core-io/src/git.ts` — `commitMessagesInRange` 포맷 변경 필요시

## Explicitly out of scope

- `backlog-join.ts` 변경 — 호출자는 이미 `slug`을 넘기고 있어 인터페이스 변경 없음.
- 되돌림(revert) 된 티켓의 자동 미완료 — grill에서 범위 밖으로 확정.
- ticket-time-stamp 기능 — 별도 기능, 별도 티켓 계열.

## Locked decisions

- 🔴 **안전 쪽 오류**: slug 매칭이 안 되면 미완료로 남긴다 (오탐보다 미탐이 낫다).
- 🔴 **하위 호환**: 기존 `resolveTicketDone(repo, slug, num)` 시그니처 유지.
- slug 추출: 커밋 메시지의 `feat(<slug>):` 패턴 또는 본문/trailer의 slug 토큰.

## Acceptance criteria

1. 같은 repo에 `ticket-done-from-git`과 `ticket-time-stamp` 기능이 있을 때,
   `ticket-done-from-git` T01 커밋이 `ticket-time-stamp` T01을 완료로 만들지 않음.
2. 기획 문서 커밋("tickets T01-T03")이 어떤 기능의 티켓도 완료로 만들지 않음.
3. `feat(ticket-done-from-git): T01 ...` 커밋은 `ticket-done-from-git` T01만 완료로 만듦.
4. slug 없는 `T01` 단독 언급은 어떤 티켓도 완료시키지 않음.
5. `pnpm -C code/web verify` green.
