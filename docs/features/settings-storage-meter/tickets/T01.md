# T01 — 측정·비우기 엔드포인트 (백엔드)

**Blocked by:** 없음 — 즉시 착수 가능

## Goal

`GET /api/storage`(총량) 와 `POST /api/storage/clear`(앱 내 캐시 비우기)를 낸다(S1·S2의 서버 절반).

## Why this slice

측정·삭제가 한 곳(백엔드)에 모여 있어 프론트와 독립적으로 검증 가능한 슬라이스다.

## Produces

- `StorageResponse { totalBytes: number | null }` contract + 두 라우트.

## Consumers

- T02 설정 화면(총량 표시·비우기 버튼).
- 기존 테스트: `app.test.ts` 에 계약 테스트 추가.

## Touched surfaces

- `code/web/contract/src/index.ts` — `StorageResponse` 추가.
- `code/web/backend/src/app.ts` (또는 새 `routes/storage.ts`) — 두 라우트.
- `code/web/backend/test/app.test.ts` — 계약 테스트.

## Explicitly out of scope

- 프론트 UI(T02). 항목별 내역·WAL 삭제·재시작.
- 비macOS 실측정 — 기본값 경로 없을 때 `totalBytes: null`.

## Locked decisions

- D2(INV-1 — 비우는 것은 파생물만), D4(저장 없음), D5(경로 규칙), D6(앱 내 범위).
- 삭제는 `localStorage` 파일 손대기 금지 — 백엔드 파생 캐시(folderCache·스냅샷 적재·discover 페이로드)만 비운다. localStorage 본체는 프론트가 `clear()` 한다(T02).

## Evidence anchors

- `clearFeatureCache`·`clearDiscoverCache`·`clearPayloadCache`·스냅샷 적재 clear seam.
- tauri.conf `identifier`(번들 ID SoT) — macOS 기본 경로組み立て 근거.
- settings 라우트 분리 선례(`routes/settings.ts`).

## Regression guards

- `backend/test/app.test.ts` 기존 라우트 테스트.
- contract drift-guard 해당 시(AGENTS.md).

## Scope

- contract 1 스키마 + 라우트 2개 + 테스트. 프론트·네이티브 금지.

## Implementation notes

- 측정 함수는 env 오버라이드(`GOOTTE_WEBKIT_DATA_DIR`)를 받아 테스트가 픽스처 디렉토리를 가리키게 한다.
- 디렉토리 재귀 합산은 동기 walks + try/catch → 실패 시 `null`(죽지 않는다).
- `POST /api/storage/clear` 는 `{ ok: true }` 응답. 비운 항목을 주석에 명시한다.

## Acceptance criteria

- 픽스처 디렉토리 크기와 응답이 일치한다(A1).
- clear 후 백엔드 캐시가 비워져 다음 read 가 재계산한다(A2).
- 경로 없음 → `null`, 200 유지(A3).
- `pnpm verify` green.

## Verification

- 신규 계약 테스트 + `pnpm verify`.
