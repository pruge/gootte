# T01 — 차단 목록(blockedCopies) 으로 작업 가지 숨기기

Time: started=2026-08-30T00:00:00+09:00 finished=2026-08-30T13:05:00+09:00

## Goal

gootte 자기 저장소에 `blockedCopies: string[]` 를 두고, 해당 slug 의 격리 사본을 read-time
필터로 화면에서만 숨긴다. 실제 worktree 는 지우지 않는다(INV-2). 설정 대화상자의 목록에서
해제하고, 미해소 카드의 "숨기기" 버튼으로 바로 추가할 수 있다.

## Why this slice

매번 stale crew 가 뜰 때마다 캡틴이 `~/.treehouse` worktree 를 직접 지우는 것은 파괴적이고
번거롭다. "보지 않겠다" 는 사용자 결정이므로 gootte 자기 저장소(INV-5)에 두는 것이 제품
불변식과 맞다 — 삭제 없이 화면에서만 걷어내고, 언제든 해제할 수 있다.

## Produces

- `contract` `Settings.blockedCopies`, `SettingsResponse`(extend 로 자동 포함), `SettingsUpdateRequest.blockedCopies`
- `core-io` `writeSettings` merge(`blockedCopies`), `DEFAULTS`
- `backend` `inProgressFor` read-time 필터, PUT `/api/settings` `blockedCopies` 처리
- `frontend` `useBlockedCopies`(query), `FeaturesView` "숨기기" 버튼, `SettingsDialog` "차단한 작업 가지" 목록
