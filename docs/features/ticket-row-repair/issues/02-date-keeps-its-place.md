# 02 — 날짜가 없어도 자리가 흔들리지 않는다

**What to build:** 할일 목록 한 줄에서 **완료일 칸을 항상 그린다.** 날짜가 없으면 같은 너비의
빈 칸이 그 자리에 남아, 뒤따르는 것들이 당겨지지 않는다.

**Blocked by:** 없음 — 지금 착수 가능

**Status:** resolved (2026-08-09)

## 캡틴 지시 (2026-08-09)

> **check 목록 표시할때, 처리중일때 날짜가 없는데 위치가 어긋나니. 날짜 공간을 잡아두도록하자.**

## 왜 처리중인 줄에만 없나

완료일은 **`resolved` 에만** 붙는다. 처리중이거나 아직 안 끝난 티켓은 끝난 날이 없으니 당연히 없다.
🟢 **이건 고칠 것이 아니다** — 없는 날짜를 지어내면 그게 거짓말이다.
고칠 것은 **없다는 이유로 자리까지 사라지는 것**이다.

## 완료 시 시연 가능한 것

캡틴이 할일 목록을 본다. 끝난 티켓과 아직 안 끝난 티켓이 섞여 있어도,
**완료일 자리가 줄마다 같은 폭으로 남아 있어** 날짜가 있는 줄과 없는 줄이 서로 밀지 않는다.

## 완료 조건

- **완료일 칸을 늘 그린다.** 값이 없으면 **같은 너비의 빈 칸**이다.
- 🔴 **없는 날짜를 채우지 않는다.** 빈 칸은 비어 있어야 한다 — `—` 같은 대체 문자도 넣지 않는다.
  🔴 이 목록에는 이미 `—` 가 **번호 없는 티켓**을 뜻하는 자리로 쓰이고 있어, 날짜 칸에 같은 문자를
  쓰면 **두 가지 뜻이 한 화면에서 겹친다.**
- **날짜가 있는 줄의 모양은 지금과 같다.** 이 티켓은 없는 쪽만 고친다.
- 칸 너비는 **날짜 서식(`YYYY-MM-DD`) 한 벌이 잘리지 않고 들어가는 만큼**이다.
  🔴 **글자 수로 잡지 말고 숫자 폭이 고정된 글꼴 설정을 유지한 채로 잡아라** — 지금 이 칸이
  그렇게 그려지고 있고, 그걸 잃으면 날짜끼리도 서로 밀린다.
- 좁은 화면에서 줄이 접힐 때 **빈 칸 때문에 이상한 빈 줄이 생기지 않는다.**
- `pnpm verify` green.

## 🔴 이 지시가 해결하지 않는 것 — 미리 말해 둔다

**이걸 해도 모든 줄의 날짜가 한 세로줄에 서지는 않는다.**

날짜 앞에 오는 **처리중 표시가 가지 이름을 담아 줄마다 너비가 다르기** 때문이다.
캡틴이 지시한 "자리를 잡아 둔다" 는 확실히 해결되지만, **줄 전체를 표처럼 세로로 맞추는 것**은
줄의 배치 방식 자체를 바꾸는 별개의 일이고 사양 §열린 결정 Q1 로 캡틴에게 열려 있다.

🔴 **이 티켓에서 배치 방식을 바꾸지 마라.** 지시받은 것보다 크게 손대면 무엇이 좋아지고 무엇이
나빠졌는지 갈리지 않는다.

## 테스트

**이 티켓이 이 칸을 처음 덮는다.**

| 상황 | 기대 |
|---|---|
| 🔴 완료일이 없는 티켓 | 완료일 칸이 **그려진다.** 자리가 사라지지 않는다 |
| 🔴 같은 상황 | 그 칸이 **비어 있다.** 대체 문자도, 지어낸 날짜도 없다 |
| 완료일이 있는 티켓 | 지금처럼 날짜가 보인다 |
| 🔴 날짜 있는 줄과 없는 줄이 나란히 있다 | 두 줄의 완료일 칸 **폭이 같다** |

🔴 **두 번째 줄이 첫 번째 줄의 짝이다.** 자리를 잡는다면서 무언가로 채우면 화면이 없는 사실을
말하게 되고, 그건 자리가 어긋나는 것보다 나쁘다.

## 이 티켓이 하지 않는 것

- **처리중 표시 고치기.** [01](01-in-progress-means-now.md) 이 한다.
- **줄을 표로 바꿔 모든 칸을 세로로 맞추기.** 사양 §열린 결정 Q1.
- **없는 날짜 지어내기·추정하기.** 완료일은 문서가 말한 것만 쓴다.
- **다른 칸의 자리 잡기.** 지시는 날짜 칸이었다. 다른 칸이 걸리면 그때 따로 본다.

## 캡틴 확인

- **어디서** — gootte 대시보드에서 **끝난 티켓과 안 끝난 티켓이 섞인** 기능을 연다.
- **무엇을** — 줄들을 위아래로 훑으며 **완료일 자리**를 본다.
- **무엇이 보여야 하나** — 날짜가 없는 줄에도 그 자리가 **같은 폭으로 비어 있고**,
  날짜가 있는 줄과 없는 줄이 서로 밀지 않는다. **빈 자리에 아무 글자도 없다.**

자리가 실제로 눈에 편해졌는지는 테스트가 판정할 수 없어 캡틴 눈이 필요하다.
