# T03 — 구 프론트 자식 코드 삭제 (contract)

**Blocked by:** T02 — preview arm 이 backend 를 본 뒤에야 지운다

## Goal

죽은 코드(`FrontendMode`·관련 env·프론트 자식 잔재)를 걷는다. 남기면 다음 사람이 preview 경로가 있는 줄 안다.

## Why this slice

contract 단계 — migrate 된 뒤 옛 메커니즘을 걷는다.

## Produces

- mode 없는 `main.rs`: backend 자식 1개 + backend 창이 유일한 길.

## Consumers

- `tauri-dev.sh` (env 지정 삭제).
- `pnpm dev`(웹 dev — 무관, 확인만).

## Touched surfaces

- `code/web/src-tauri/src/main.rs` — `FrontendMode` enum·`resolve`·`mode` 필드·`GOOTTE_TAURI_FRONTEND_MODE` 분기·`frontend_port` 사용처 정리.
- `scripts/tauri-dev.sh` — `GOOTTE_TAURI_FRONTEND_MODE=dev` 삭제(dev arm 기본?contra 아래).
- `scripts/dev-frontend.sh`·`proc-title.mjs` — 유지(dev 가 쓴다). 지우지 않는다.

## Explicitly out of scope

- dev arm(vite dev spawn + `--import` 제목) — 살아 있다.
- ports 형식·e2e.

## Locked decisions

- D8(enum 삭제).
- dev arm 판정: env 없이 `cfg!(debug_assertions)` 로 dev(현 `resolve` 의 폴백과 같은 값)?contra — 아니다. tauri-dev.sh 가 dev 를 **명시**하던 계약을 유지하려면 env 자리는 둬야 한다. 그래서 enum 은 지우되 모드 판정은 남긴다: `GOOTTE_TAURI_FRONTEND_MODE` 가 없으면 debug=dev·release=backend-only. tauri-dev.sh 의 export 는 유지한다(명시 계약). enum·Preview 변형·frontend 자식 코드만 삭제.

## Evidence anchors

- T02 landed 뒤 `FrontendMode`·`Preview`·`frontend_port`·`GOOTTE_TAURI_FRONTEND_MODE` 잔여 참조 전수(grep).

## Regression guards

- `cargo check` + `clippy`.
- `pnpm dev:tauri` 수동 확인(dev arm HMR 생존) — 캡틴 환경.

## Scope

- main.rs 정리 + dev 스크립트 확인. 기능 변경 금지.

## Implementation notes

- `StackConfig.frontend_port` 는 ports 파일 형식이 살아 있으므로 resolve 는 유지하되 사용처만 없앤다 — 읽고 버리는 값이 되면 clippy/경고가 날 수 있으니 `_` prefix 나 구조 정리로 대응한다.
- grep 으로 `FRONTEND_PORT`·`vite_js`·`preview` 잔재를 확인한다.

## Acceptance criteria

- 죽은 참조 0개(grep).
- dev arm·설치 arm 둘 다 기동 확인.
- `cargo check`·`clippy` green.

## Verification
