# T01 — Claude Code worktree 를 감시 대상에 자동 포함
Time: started=2026-08-31T05:53:09+09:00 finished=2026-08-31T05:53:09+09:00

## Goal

`scanWorkingCopies` 가 treehouse 뿌리만 훑던 것을, **프로젝트 안의 `.claude/worktrees/*`
(Claude Code worktree)** 도 사본으로 관측하게 바꾼다. worktree 는 git worktree 라 `.git` 이
파일이고 branch·커밋 이력이 있어 treehouse 사본과 같은 규칙으로 처리중·유휴·티켓 연결이
가능하다.

## Why this slice

firstmate 와 무관하게 Claude Code 로 작업하는 경우, 그 작업이 "지금 누가 무엇을 붙들고
있나" 에서 보이지 않는다 — 감시 대상이 아니어서다. worktree 가 생성되는 순간 자동으로
올라와야 한다(캡틴 지시 2026-08-30).

## Produces

- `core-io/src/treehouse.ts` — `scanWorkingCopies(root, project, projectPaths = [])`.
  각 프로젝트 경로의 `.claude/worktrees/` 를 훑어 worktree 를 사본 하나로 센다.
  슬러그 = `<프로젝트>/claude/<워크트리명>` (treehouse `<풀>/<슬롯>` 와 겹치지 않게).
  treehouse 가 없어도(`rootExists:false`) worktree 는 관측된다(INV-4).
- `backend/src/app.ts` — `projectCopiesFor(project)` = `resolveSlug(effectiveRoots(), project)
  ?.copies` (5s TTL 캐시). 세 호출부(재갱신·서빙·features 라우트)에 넘긴다.
- `core-io/src/treehouse.test.ts` — Claude Code worktree 관측·슬러그 테스트 2건.
