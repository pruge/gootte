현 규칙(`code/web/core-io/src/secondmates.ts:18`):

```
const HOME_LINE = /^\s*home:\s*(\S+)\s*$/;
```

줄 전체가 `home: <경로>` 인 모양만 받는다. 실물은 그 모양이 아니다:

```
- gootte-mate - gootte 대시보드를 맡는 두 번째 항해사 (home: /Users/pruge/.treehouse/firstmate2-4b2429/1/firstmate2; scope: gootte 대시보드 자체에 관한 모든 일 …; projects: gootte; added 2026-08-26)
```

실측 결과 `readSecondmateHomes("/Users/pruge/Documents/ai2/firstmate2")` 가 `[]` 를 낸다 —
**착지 이후 한 번도 동작한 적이 없다.**

고칠 방향(spec D2): 줄 안 어디서든 `home:` 을 찾되 경로는 `;`, `)`, 공백 앞에서 끊는다.
기존 단독 줄 형식도 그대로 받는 상위집합이어야 한다.

🔴 **정규식 형태를 이 티켓이 지정하지 않는다.** 아래 받아들임 조건을 만족하면 된다.
