## Goal

Read-side consumers that currently call `@gootte/core-io` state-store functions directly are migrated to use `@gootte/time-ledger` package read/derived API. **This is read-side migration, NOT mutation deletion.** Badge recompute stays in `@gootte/core-io` adapter but now calls package async `replaceOpenFeatures`.

**T03 read-side only:** no old mutation storage deletion (that's T06). T03 reads from package, T06 deletes old write implementation.
