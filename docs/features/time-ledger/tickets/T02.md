old `@gootte/cli/src/time.ts` becomes compatibility facade only:
- Parse CLI args → `TicketRef`
- Call package transition API (async, await)

- Badge recompute via `@gootte/core-io` adapter
- **State mutation: 0 direct calls.** All writes go through `@gootte/time-ledger`.
