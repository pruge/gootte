## Goal

GoOtTe write adapters(CLI `runTimeCommand`, `migrate-time.ts`, backend `routes/time.ts` facade) to delegate to `@gootte/time-ledger` package API. old/new parity matrix proves equivalence. Production mutation authority is package only.

- `code/web/time-ledger/src/ledger.ts` — includes `importLegacy(records: Record<string, Partial<TicketTimeRecord>>, {mode}: {mode: 'overwrite' | 'append'})` typed admin transition
  - `mode: 'overwrite'` — existing v2 records are replaced (migrate only)
  - `mode: 'append'` — existing records preserved, new ones added
  - Loss prevention: existing records with `startedAt != null` are never overwritten in `append` mode; `overwrite` mode requires explicit opt-in and logs conflict if active record exists
