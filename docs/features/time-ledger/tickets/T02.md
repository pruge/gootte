## Goal

`@gootte/cli/src/time.ts`의 `runTimeCommand`이 `@gootte/time-ledger` package API를 소비하도록 전환한다. bare verbs, `time` command, `dropFeature` adapter, badge recompute를 포함. old/new parity matrix로 동등성을 증명.

## Why this slice

CLI가 package API를 직접 사용하면 transition semantics가 한 곳에 집중된다. old implementation은 compatibility facade로 남기되, 새로운 모든 호출은 package를 경유.

## Scope (manual files ≤ 15)

- `code/web/cli/src/time.ts` — `runTimeCommand`이 `@gootte/time-ledger` API 호출
- `code/web/cli/src/time.test.ts` — parity matrix (old vs new)
- `code/web/cli/src/migrate-time.ts` — migrate도 package 호출
- Compatibility facade: old `resolveMainRoot`, `target` 등은 `@gootte/cli` internal에 남되, 실제 state mutation은 package delegation

**NOT in scope:** dist/artifact, pi-taskflow, `@gootte/core` changes, global install.
