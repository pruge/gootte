```

  1. All writers confirmed: GoOtTe CLI, pi-taskflow, others currently idle
  2. Lifecycle write stop: all consumers paused from writing
  3. Version pin preparation: new version, integrity hash confirmed

Phase 2 — Coordinated Switch
  4. pi-taskflow: artifact download + integrity verification → package install
  5. GoOtTe CLI: new package switch (versioned bundle, Boss-approved global install if needed for live writer)
  6. Parity/readback: identical input, old vs new output comparison
  7. Resume: lifecycle write restart

Phase 3 — Verification
  8. Zero-symbol verification: all consumers use new package
  9. Lock contention test: concurrent write handled by CAS
  10. Rollback plan confirmed
```

- GoOtTe only new global install creates mixed runtime — **prohibited**. Versioned GoOtTe CLI bundle required for live writer.
- Lock-unaware pi-taskflow writer may coexist during migration window — **do not hide**.
- Boss release approval required for GitHub push/tag/release.
- Rollback uses same quiescent procedure.
