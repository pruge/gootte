## TicketRef resolve

`TicketRef{feature, ticket}` → package resolves via `ticketSourceRoot` working tree → `git cat-file -e HEAD:<rel>` fallback. Not-found or different-repo → `LedgerConflict.not-found` / `LedgerConflict.different-repo`.

## Lock/CAS defaults (locked, not unknown)

- Lock file: `<ledgerRoot>/.gootte/state.json.lock`
- Lock deadline: 2000ms
- Bounded retry: 10→100ms jittered
- Stale reclaim: same-host lock age ≥30s AND owner PID absent
- Document hash mismatch: max 3 retries → explicit `LedgerConflict.hash-mismatch`
- Unique temp + fsync + rename + possible directory fsync + readback
- Config override possible; above are defaults
