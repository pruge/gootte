### importLegacy exact behavior

- `mode: 'overwrite'` — existing v2 records are replaced. Requires explicit opt-in. If active record exists, returns `LedgerConflict` instead of overwriting.
- `mode: 'append'` — existing records preserved. Records with `startedAt != null` are NEVER overwritten in append mode; attempting to overwrite returns `LedgerConflict`.
- Loss prevention: no silent data loss. Every conflict is explicit.
- **Result type:** `Promise<LedgerResult<ImportSummary> | LedgerConflict>` — single coherent result. `LedgerConflict[]` union prohibited.

### `TicketRef` resolve

`TicketRef{feature, ticket}` → package resolves via `ticketSourceRoot` working tree → `git cat-file -e HEAD:<rel>` fallback. Not-found or different-repo → `LedgerConflict.not-found` / `LedgerConflict.different-repo`.

### Lock/CAS defaults (locked, not unknown)

- Lock file: `<ledgerRoot>/.gootte/state.json.lock`
- Lock deadline: 2000ms
- Bounded retry: 10→100ms jittered
- Stale reclaim: same-host lock age ≥30s AND owner PID absent
- Document hash mismatch: max 3 retries → explicit `LedgerConflict.hash-mismatch`
- Unique temp + fsync + rename + possible directory fsync + readback
- Config override possible; above are defaults

### Corrupt fail-closed

`read()`, `hasTimeRecords()` validate v2 schema. Corrupt/invalid → `LedgerConflict.corrupt`. No silent data loss.

### `replaceOpenFeatures` narrow derived-cache parity

Lock/CAS under state write:
- **No state / v1 → v1 badge schema preserved.** Do not invent tickets for v2 promotion.
- **v2 → tickets preserved byte/semantic lossless.** Only openFeatures replaced.
- **Identical values → 0 writes.** No-op when no actual change.
- **Generic CRUD is NOT exposed.** This is the sole derived-cache write path.
