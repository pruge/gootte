```typescript
// Independent transition cases, not single linear flow:

start(ref: TicketRef, at: string, options?: { update?: boolean }): Promise<LedgerResult | LedgerConflict>
pause(ref: TicketRef, at: string): Promise<LedgerResult | LedgerConflict>
resume(ref: TicketRef, at: string): Promise<LedgerResult | LedgerConflict>
end(ref: TicketRef, at: string): Promise<LedgerResult | LedgerConflict>
cancel(ref: TicketRef): Promise<LedgerResult | LedgerConflict>
drop(ref: TicketRef, at: string): Promise<LedgerResult | LedgerConflict>
reopen(ref: TicketRef, at: string): Promise<LedgerResult | LedgerConflict>

// Typed admin transition (for migrate, T02):
importLegacy(records: Record<string, Partial<TicketTimeRecord>>, options: { mode: 'overwrite' | 'append' }): Promise<LedgerResult | LedgerConflict[]>
```

### `importLegacy` exact behavior

- `mode: 'overwrite'` — existing v2 records are replaced. Requires explicit opt-in. If active record (startedAt != null, finishedAt == null) exists, returns `LedgerConflict` instead of overwriting.
- `mode: 'append'` — existing records preserved. New records added. Records with `startedAt != null` are NEVER overwritten in append mode; attempting to overwrite returns `LedgerConflict`.
- Loss prevention: no silent data loss. Every conflict is explicit.

### `TicketRef` resolve

`TicketRef{feature, ticket}` → package resolves via `ticketSourceRoot` working tree → `git cat-file -e HEAD:<rel>` fallback. Not-found or different-repo → `LedgerConflict.not-found` / `LedgerConflict.different-repo`.

### Lock/CAS defaults (locked, not unknown)

- Lock file: `<ledgerRoot>/.gootte/state.json.lock`
- Lock deadline: 2000ms
- Bounded retry: 10→100ms jittered
- Stale reclaim: same-host lock age ≥30s AND owner PID absent
- Document hash mismatch: max 3 retries → explicit `LedgerConflict.hash-mismatch`
- Unique temp + fsync + rename + possible directory fsync + readback
- Config override possible; above are defaults
