## Goal

## Why this slice

모든 티켓이 landed 된 뒤, 전체 코드베이스가 여전히 정상인지 최종 검증한다. git 잔존 여부, settings 통합, worktree 감지, state.json 갱신도 같이 확인한다.

## Produces

`pnpm verify` 녹색. git 관련 코드 잔존 없는 코드베이스.

## Scope

1. `pnpm verify` 실행
2. 모든 테스트 통과 확인
3. TypeScript 컴파일 에러 없음
4. 잔여 git import/참조 없음 — `grep -r "from.*git" code/web/`
