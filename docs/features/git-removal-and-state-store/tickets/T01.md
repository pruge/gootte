# T01 — git.ts 파일 전면 삭제, 소비처 정리

**Blocked by:** 없음
**Status:** open
**Time:**

## Goal

`core-io/src/git.ts` 파일을 삭제하고, 모든 import를 제거한다.

## Why this slice

git 하위프로세스는 readFeatures 비용의 70%를 차지한다(spec §3 정정). 파일 하나를 지우면 모든 소비처가 끊기고, 끊긴 자리에 새 구조를 붙이는 것이 이후 티켓의 몫이다. 가장 먼저 해야 하는 기계적 정리.

## Produces

git.ts 없는 코드베이스. 모든 소비처에서 git import가 제거된 상태.

## Consumers

- `core-io/src/features.ts` — `CopyResolver`, `resolveFile` (T02에서 처리)
- `core-io/src/treehouse.ts` — `scanWorkingCopies`, `touchedOnBranch`
- `backend/src/snapshot.ts` — `sameStamps`, `recordProjectScan`
- `backend/src/routes/time.ts` — `currentBranch`
- `backend/src/app.ts` — `currentBranch`

## Touched surfaces

- `core-io/src/git.ts` — 파일 전체 삭제
- `core-io/src/index.ts` — `export * from "./git"` 제거
- `core-io/src/features.ts` — git import 6개 제거
- `core-io/src/treehouse.ts` — git import 4개 제거
