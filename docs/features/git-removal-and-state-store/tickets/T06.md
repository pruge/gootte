# T06 — 사이드바 배지 → state.json에서 읽기

**Blocked by:** T05
**Status:** open
**Time:**

## Goal

사이드바 `openFeatures`를 `state.json`에서 즉시 서빙한다.

## Why this slice

T05가 state.json 모듈을 만들면, 사이드바 배지는 스냅샷이 아니라 state.json에서 바로 읽을 수 있다. 3초 스피너 딜레이, `scheduleCountFill` 비동기 카운팅이 전부 불필요해진다.

## Produces

즉시 배지 표시. 3초 딜레이 제거. `scheduleCountFill` 제거.

## Consumers

- `frontend/src/components/sidebar/Sidebar.tsx` — 배지 표시
- `frontend/src/lib/query.ts` — `invalidateOpenCount`

## Touched surfaces

- `backend/src/app.ts` — `openCountBySlug`·`scheduleCountFill`·`rememberOpenCount`·`invalidateOpenCount` 제거
- `backend/src/app.ts` — `/api/projects`가 state.json에서 읽도록 변경
- `backend/src/app.ts` — `featuresFor` 호출 후 `updateProjectState` 호출
- `backend/src/server.ts` — `invalidateBadge` 제거
- `frontend/src/components/sidebar/Sidebar.tsx` — `SPINNER_DELAY_MS`·`useSpinnerAfterDelay` 제거
- `frontend/src/lib/query.ts` — `invalidateOpenCount` 제거

## Explicitly out of scope

## Implementation notes

- 위치: `<프로젝트 루트>/.gootte/state.json` (T05와 동일)
- `/api/projects`는 각 프로젝트의 `readState(projectDir)`로 `openFeatures`를 즉시 채운다
- `featuresFor` 완료 후 `updateProjectState(projectDir, features)`로 state.json을 갱신
- WS broadcast로 프론트에 알림 → 프론트는 React Query refetch
