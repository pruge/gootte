# T08 — scanWorkingCopies git 제거

**Blocked by:** T01
**Status:** open
**Time:**

## Goal

처리중 관측에서 git 호출을 제거한다.

## Why this slice

`scanWorkingCopies`는 worktree의 브랜치 이름과 미커밋 파일을 git으로 읽는다. conflict가 없어지고, 처리중 판정이 `Time: started=`로 바뀌었으므로(ADR-0001), git 없이 worktree 존재 여부만 확인하면 충분하다.

## Produces

git 없는 `scanWorkingCopies`. worktree 존재 여부만 판정.

## Consumers

- `app.ts` — `inProgressFor`에서 호출
- `app.ts` — `refreshInProgress`에서 호출

## Touched surfaces

- `core-io/src/treehouse.ts` — `scanWorkingCopies`에서 `currentBranch`·`findGitRepo` 제거
- `core-io/src/treehouse.ts` — `touchedOnBranch`에서 `commitTouchedFiles` 제거
- `core-io/src/treehouse.ts` — `observe` 함수에서 git 판정 제거

## Explicitly out of scope

- `scanWorkingCopies` 자체 삭제 — 존재 여부만 판정하도록 변경

## Locked decisions

- **D4** — 처리중 관측은 worktree 존재 여부만 (spec)

## Evidence anchors

## Regression guards

- 🔴 `pnpm verify` 통과
- 🔴 `scanWorkingCopies`가 git을 호출하지 않음

## Scope

1. `observe` 함수에서 `findGitRepo`·`currentBranch` 호출 제거
2. worktree 디렉토리 존재 여부만 판정 (statSync)
3. `touchedOnBranch` 함수에서 `commitTouchedFiles` 제거
4. 브랜치 이름 없이 `branch: ""` 고정
5. state: 디렉토리 존재하면 "working", 아니면 "no-repo"

## Implementation notes

- `findGitRepo` 대신 `existsSync(dir)` + `statSync(dir).isDirectory()`
- `currentBranch` 제거 → `branch: ""` 고정
- `touchedOnBranch` 제거 → `touched: []` 고정
- `state` 판정: 디렉토리 존재 여부만

## Acceptance criteria

- AC1 — `scanWorkingCopies`가 git을 호출하지 않음
- AC2 — worktree 존재 여부는 파일시스템으로 판정
- AC3 — `tsc --noEmit` 통과
