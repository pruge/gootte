# T04 — 축 2 (커밋 감시) 제거

**Blocked by:** T01
**Status:** open
**Time:**

## Goal

`watch.ts`의 git 관련 감시 경로를 제거한다.

## Why this slice

축 2(`gitRefPaths`, `gitW`)는 `.git/HEAD`·`refs/`를 감시해 커밋 변경을 잡는다. conflict 판정이 없어지고, `sameStamps`가 사라지면, 이 감시는 할 일이 없다. 문서 감시(축 1)만으로 충분하다.

## Produces

커밋 감시 없는 watch 시스템. 축 1(문서) + 안전망(15초 타이머)만 남음.

## Consumers

- `server.ts` — `watchers`·`snapshotRevalidator` 설정
- `snapshot-revalidator.ts` — HEAD 비교 로직

## Touched surfaces

- `core-io/src/watch.ts` — `gitRefPathsOf`·`gitRefPaths`·`gitW` 삭제
- `backend/src/server.ts` — HEAD 재검증 관련 로직 정리
- `backend/src/snapshot-revalidator.ts` — HEAD 비교 로직 제거

## Explicitly out of scope

- 축 1 (문서 감시) 유지
- 안전망 타이머(15초) 유지 — 감시 실패 시 대비용

## Locked decisions

- **D4** — 처리중 관측은 worktree 존재 여부만 (spec)

## Evidence anchors
