# T03 — sameStamps · snapshotNeedsRefresh 제거

**Blocked by:** T01
**Status:** open
**Time:**

## Goal

스냅샷 staleness 판정에서 git 기반 로직을 제거한다.

## Why this slice

`sameStamps`는 매번 `headCommit` + `hasTrackedUncommittedChange`를 호출해 git 하위프로세스 2개를 만든다. T01이 git import를 제거하면 이 함수는 더 이상 동작하지 않는다. 축 1(문서 감시)이 변경을 잡으므로, staleness 판정은 `sameCopies`만으로 충분하다.

## Produces

`stamps` 없는 스냅샷 스키마. `snapshotNeedsRefresh`가 `sameCopies`만으로 판정.

## Consumers

- `snapshot-revalidator.ts` — `snapshotNeedsRefresh` 호출
- `app.ts` — `featuresFor`에서 `snapshotNeedsRefresh` 호출

## Touched surfaces

- `backend/src/snapshot.ts` — `sameStamps`·`readSnapshotStamps`·`SnapshotStampInfo` 삭제
- `backend/src/snapshot.ts` — `snapshotNeedsRefresh`를 `sameCopies`만 사용하도록 변경
- `backend/src/snapshot.ts` — `recordProjectScan`에서 `stamps` 필드 제거
- `backend/src/snapshot.ts` — `SnapshotProject` 스키마에서 `stamps` 제거
