# T02 — CopyResolver 클래스 삭제

**Blocked by:** T01
**Status:** open
**Time:**

## Goal

`features.ts`의 `CopyResolver` 클래스와 이를 사용하는 `resolveFile` 함수를 삭제한다.

## Why this slice

T01이 git import를 제거하면 `CopyResolver`는 `headCommit`·`uncommitted`·`isAncestor`·`hasRev`를 부를 수 없게 된다. 이 클래스는 conflict(갈라짐) 판정의 핵심이고, conflict는 더 이상 필요 없다(D3). 클래스와 그 위의 `resolveFile`·`representative`를 함께 지운다.

## Produces

conflict 없는 `readFeatures`. `Feature.conflict` 필드가 빈 배열 또는 제거된 상태.

## Consumers

- `FeatureCard.tsx` — `ConflictBadge` 표시 (T07에서 처리)
- `TicketRow.tsx` — `ConflictBadge` 표시 (T07에서 처리)
- `FeatureTree.tsx` — `ConflictBadge` 표시 (T07에서 처리)
- `CardDialog.tsx` — `ConflictBadge` 표시 (T07에서 처리)

## Touched surfaces

- `core-io/src/features.ts` — `CopyResolver`·`resolveFile`·`representative`·`CopySlug` 삭제
- `core-io/src/features.ts` — `buildFeatures`에서 conflict 계산 코드 제거
- `contract/src/index.ts` — `FeatureConflict` 스키마 삭제, `Feature.conflict` 필드 제거
- conflict 관련 테스트 케이스 삭제
