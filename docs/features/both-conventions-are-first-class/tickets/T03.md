## Acceptance criteria

캡틴이 아래를 확인한다:

1. 신관례 티켓(`tickets/T<NN>.md`)을 열면 초록이 풀린다.
2. 그 기능의 신관례 티켓을 다 읽으면 기능 카드 머리글의 초록도 풀린다.
3. 다시 열어도, 새로고침해도 읽음이 유지된다.
4. 신관례만 쓰는 기능을 완료·예약·폐기 칸에 놓았을 때, 다 읽었으면 대기로 되올라오지 않는다.
5. 명세(`spec.md`)·결정 기록(`adr/`)은 열어도 여전히 아무 표시가 없다.
6. 다른 기능의 신관례 티켓을 선행으로 건 티켓이, 그 선행 완료 뒤 착수 가능으로 바뀐다.
