# T01 — 백로그 신호·감시 제거

**Blocked by:** 없음 — 즉시 착수 가능

## Goal

`ChangeEvent kind:"backlog"` 와 백로그 감시 배선을 삭제한다. 이후 백로그 파일 변경은 어떤 무효화도 일으키지 않는다(S2).

## Why this slice

신호+감시가 살아 있으면 조인(T02)을 먼저 걷을 수 없다(타입·방송이 조인을 참조한다). 감시 쪽부터 끊어야 뒤가 단순해진다.

## Produces

- `ChangeEvent` 에 `backlog` 변형이 없음. 폴백 판정(`failures`)에서 `backlog` 축이 없음.

## Consumers

- 프론트 `useLiveSync` — `backlog` 분기를 삭제하고, 그 자리의 전체 invalidate 가 사라진다.
- 백엔드 `startWatchers` — `rebindBacklog`·백로그 워처 생성·`watchBacklogImpl` 주입이 사라진다.
- `server.ts` — 폴백 판정에서 백로그 축을 안 본다(현재 home 을 안 넘기므로 사실상 no-op 정리).
- 기존 테스트: `watchers.test.ts`·`realtime-t05.test.ts`·`live.test.ts` 의 backlog 케이스.

## Touched surfaces

- `code/web/contract/src/index.ts` — `ChangeEvent` union 에서 `backlog` 변형과 주석 삭제.
- `code/web/backend/src/watchers.ts` — `rebindBacklog`·`firstmateHome` 옵션·`startBacklogWatchers`·`failures.backlog` 삭제.
- `code/web/frontend/src/lib/live.ts` — `kind:"backlog"` 분기 삭제.
- 관련 테스트 파일의 backlog 케이스 삭제·수정.

## Explicitly out of scope

- 조인 본체(`applyBacklogStatus`·`readBacklogTasks`·파서)는 T02 몫. 여기선 건드리지 않는다.
- `firstmateHome` 설정·discover·secondmates 는 유지(S4).
- `watch-fallback` 신호와 폴백 폴러는 유지한다.

## Locked decisions

- D5(제거 범위: 신호·감시·조인만), D2(INV-1), D3(INV-3).
- `rebindBacklog` 호출처가 없고 서버가 home 을 넘기지 않아 감시는 이미 no-op — 동작 변경 없는 정리다(스윕 확인 2026-09-11).

## Evidence anchors

- `ChangeEvent` 정의와 `backlog` 주석.
- `startWatchers` 의 `failures`·`startBacklogWatchers`·`rebindBacklog`.
- `useLiveSync` 의 `backlog` 분기(전체 invalidate).

## Regression guards

- `backend/test/watchers.test.ts`, `backend/test/realtime-t05.test.ts`, `backend/test/live.test.ts`.
- contract 변경 시 소비처 회귀(AGENTS.md contract verify + drift-guard 해당 시).

## Scope

- 위 Touched surfaces 의 삭제 + 테스트 정리. 그 외 파일 금지.

## Implementation notes

- `failures` 객체에서 `backlog` 키를 빼고, `syncFallback` 판정이 projects·plan 두 축으로만 돈다.
- contract 주석의 신호 목록에서 `backlog` 줄을 지운다.

## Acceptance criteria

- 백로그 파일 쓰기 후 WS 로 어떤 메시지도 안 나가고, 프론트 전체 invalidate 가 일어나지 않는다(A2).
- `pnpm verify` green(A5).

## Verification

- `pnpm verify` 전체. 추가로 백로그 파일 쓰기 → WS 수신 없음 수동 확인.
