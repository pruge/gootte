# T01 — CLI `start`/`end` 명령으로 티켓에 시각 기록

## Goal

`gootte start <feature-slug> <ticket>` / `gootte end <feature-slug> <ticket>` CLI 명령을 추가해
신관례 티켓 문서(`tickets/T<NN>.md`)에 `Time:` 줄을 삽입·갱신한다.
커밋은 하지 않는다 — PR에 묻어간다(grill D3).

## Why this slice

시간 기록의 **쓰기** 쪽이다. T02가 이 줄을 **읽어서** 대시보드에 보여주는 쪽이다.
쓰기를 먼저 만들어야 읽기를 실물 파일로 검증할 수 있다.

## Produces

- `gootte start <feature> <ticket>` — 티켓 파일에 `Time: started=<ISO>` 줄 삽입.
- `gootte end <feature> <ticket>` — 같은 줄에 `finished=<ISO>` 추가.

## Touched surfaces

- `code/web/cli/src/main.ts` — `start`/`end` 명령 라우팅 추가
- `code/web/cli/src/commands.ts` — `startText()`/`endText()` 함수
- `code/web/cli/src/cli.test.ts` — 명령 시험

## Explicitly out of scope

- 파서가 `Time:` 줄을 읽는 것 — T02.
- 대시보드 표시 — T02.
- 백로그 `time:` 줄 제거 — T02.
- 크루 자동화 규칙 — firstmate 쪽, 별도.

## Locked decisions

- 🔴 **커밋 안 함** — 파일만 편집한다(grill D3).
- 🔴 **중복 방지** — 이미 `Time:` 줄이 있으면 `start` 에러. 이미 `finished`가 있으면 `end` 에러.
  `Time:` 줄이 없는데 `end` 호출해도 에러.
- 형식: `Time: started=2026-08-29T10:30:00+09:00 finished=2026-08-29T11:15:00+09:00`
  — `Status:` 줄과 같은 위치(제목 뒤, 본문 앞).
- 프로젝트 경로는 `resolveProjectPath` 재사용(cwd + `GOOTTE_ROOTS`).
- 티켓 파일이 없으면 에러.

## Acceptance criteria

1. `gootte start ticket-done-from-git T01` → 티켓 파일에 `Time: started=<ISO>` 삽입됨.
2. `gootte end ticket-done-from-git T01` → 같은 줄에 `finished=<ISO>` 추가됨.
3. 이미 시작된 티켓에 `start` → 에러 메시지, 파일 안 바뀜.
4. 시작 안 된 티켓에 `end` → 에러 메시지, 파일 안 바뀜.
5. 없는 기능/티켓 → 에러.
6. `pnpm -C code/web verify` green.

## Verification

routine. 파일 쓰기 결과를 단위 시험으로 고정 — 임시 디렉터리에 실물 티켓 모양의 파일을
만들고 `start`/`end` 후 내용을 단언한다.
