# T03 — 캡틴 검수

**캡틴 확인:** 필요

## Goal

구현이 끝난 뒤 캡틴이 직접 확인한다.

## 검수 항목

1. `gootte start <feature> <ticket>` / `gootte end <feature> <ticket>` 이 티켓 파일에
   `Time:` 줄을 올바르게 삽입·갱신하는가.
2. `plan` 탭에서 `Time:` 줄이 있는 티켓에 마우스를 올리면 걸린 시간이 뜨는가.
3. `steps` 탭에서도 같은 값이 같은 문구로 뜨는가.
4. `Time:` 줄이 없는 티켓에는 아무것도 안 뜨는가.
5. 문구가 읽기에 자연스러운가.
6. (T04/ADR-0001) git 커밋만으로는 완료가 안 뜨는가 — `gootte end`를 안 부르면 화면에 안 뜨는지 확인.
7. (T04) 구관례(`issues/`) 티켓 판정은 회귀 없이 그대로인지 확인.
