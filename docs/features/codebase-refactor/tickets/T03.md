## Implementation notes

- AREA_LABEL을 contract에 추가할 때, `BoardAreas` 타입이 이미 contract에 정의되어 있는지 확인. 있다면 그 위에 Record를 만들면 됨
- isTicketDoc의 정규식 차이(app.ts는 issues/에서 `.md` 확장자 검사 안 함)는 의도적 차이로 유지. unified 함수는 `.md` 검사를 기본으로 하되, app.ts 호출부에서 별도 처리 가능하도록 설계
- `clearDiscoverCacheMemory` → `clearDiscoverCache` 교체 시, 테스트의 의도(메모리 캐시만 비우기)가 동일하게 유지되는지 확인
