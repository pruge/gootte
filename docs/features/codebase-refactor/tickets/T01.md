## Goal

호출자 없는 함수, 컴포넌트, 훅, 파일을 삭제하고, import 되지 않는 npm 의존성을 제거한다. 검증은 기존 테스트가 통과하는 것으로 충분하다.

## Why this slice

죽은 코드는 유지보수 비용만 올리고, 불필요한 의존성은 빌드 시간과 보안 노출면을 늘린다. 이 작업은 다른 어떤 변경에도 영향을 주지 않는 가장 안전한 첫 단계다.

## Produces

삭제된 코드/의존성이 없는 깔끔한 코드베이스. 빌드 산물이 약간 작아진다.

## Consumers

이 티켓이 다루는 모든 심볼은 **호출자가 0**이므로 소비처가 없다. 단, `dnd.ts`의 테스트(`test/process-dnd.test.ts`)가삭제 대상이므로 해당 테스트도함께 삭제하거나 수정이 필요하다.
