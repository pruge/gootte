# T04 — 큰 파일 분리

**Blocked by:** T03

**Time:** started=2026-09-08T05:08:47+09:00 finished=2026-09-08T05:21:47+09:00

## Goal

400줄 이상의 큰 파일을 도메인별 하위 모듈로 분리하여 가독성과 유지보수성을 높인다.

## Why this slice

하나의 파일에 여러 도메인이 섞이면 관련 코드를 찾기 어렵고, 병렬 편집 시 충돌 위험이 커진다. 분리는 동작 변경 없이 구조만 개선한다.

## Produces

- app.ts에서 분리된 라우트 모듈 3개
- ProcessView.tsx에서 분리된 하위 컴포넌트 2개
- PlanView.tsx에서 분리된 하위 컴포넌트/유틸
- SettingsView.tsx에서 분리된 카테고리 패널

## Consumers

이 티켓이 다루는 모든 컴포넌트/라우트는 **App.tsx와 Hono 서버에서만 entry point**가 있다. 분리 후에도 동일한 entry point를 통해 접근된다.

## Implementation notes

- app.ts에서 라우트를 추출할 때, `app` 인스턴스를 어떻게 전달할지 결정 필요. Hono의 `app.route()` 사용이 자연스러움
- ProcessView의 TicketLine은 props가 많을 수 있으니 인터페이스를 명확히 정의
- 기존 테스트에서 app.ts를 직접 import하고 있다면, re-export 패턴으로 하위 호환 유지
- 분리된 파일은 같은 디렉토리에 두되, renamed export는 기존 import를 깨뜨리지 않도록 주의
