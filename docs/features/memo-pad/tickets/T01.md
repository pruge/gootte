# T01 — memo-pad: 캡틴의 빠른 생각을 적는 메모 탭
Time: started=2026-09-01T23:00:00+09:00 finished=2026-09-02T00:10:00+09:00

## Goal

`memo` 탭을 만든다. 캡틴이 기능을 쓰기 전에 떠오르는 생각을 프로젝트별로 적고·고치고·지울 수
있다. 메모는 gootte 자기 저장소(`GOOTTE_DATA_DIR/memos/<project>.json`)에만 쓴다 — 관리대상은
한 글자도 건드리지 않는다(INV-2).

## Why this slice

캡틴의 생각을 적을 곳이 없다. `docs/features/` 는 INV-2(읽기 전용)라 쓸 수 없고,
`GOOTTE_DATA_DIR` 은 저장할 자격이 있는 칸(INV-5)이지만 도구가 없었다. 하드룰 INV-5 가
저장을 허락하는 칸이다.
