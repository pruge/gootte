프런티어 비었음. 캡틴이 권고를 승인하며 즉시 착수를 지시하셨다 — spec·티켓 착수 가능.

## 캡틴 지시 (원문, 2026-08-27)

> 각 ticket당 작업 시간을 보여주었으면 하는데. 가능할까?

firstmate 가 세 갈래(PR 기록에서 계산 / 지시서 파일 시각 / 끝낼 때 기록에 남기기)를 올리고
3번+1번 조합을 권고하자:

> plan, steps 탭에서 ticket에 마우스를 올리면 걸린시간 약 14분 이렇게 보여주게해. 권고 승인 바로 진행하고 병합해.

확정된 것: **표시 자리는 plan·steps 두 탭의 티켓 hover**, **문구는 "약 14분" 꼴**,
**앞으로는 정확히 기록하고 이미 끝난 것은 PR 기록에서 되짚어 채운다**.

## 닿는 불변식

- **INV-1 파생물만** — 🔴 걸린 시간(분)은 **저장하지 않는다.** 저장하는 것은 착수·완료 **시각**(사실)이고,
  분은 볼 때마다 다시 뺀다.
- **INV-2 읽기 전용** — gootte 는 백로그를 읽기만 한다. 시각을 **쓰는 것은 firstmate** 다.
- **INV-4 결정적·LLM-free** — 시각은 기록에서 읽은 것뿐. 추정·보간 금지.
- **INV-5 계획은 저장하고 사실은 저장하지 않는다** — 시각은 사실이므로 gootte 의 계획 DB 에 넣지 않는다.

## 결정

### D1 — 시각은 백로그 메모에서 읽는다. gootte 는 GitHub 에 묻지 않는다.

F8 이 이 결정을 강제한다: gootte 서버에는 외부 호출이 하나도 없고, 화면을 그리려고 GitHub 을
부르기 시작하면 인증·요금·지연·오프라인이 전부 이 제품의 문제가 된다.

그러므로 **firstmate 가 완료 시점에 시각을 백로그 메모에 적고, gootte 는 그것을 읽는다.**
firstmate 는 이미 그 기록의 소유자이므로 새 저장소도 새 계약도 생기지 않는다.

### D2 — 기록 형식은 한 줄, 시각 둘

```
time: started=2026-08-27T12:48:43+09:00 finished=2026-08-27T13:06:12+09:00
```

- **분이 아니라 시각을 적는다** — 분은 파생물이라 저장하면 INV-1 위반이고, 나중에 표기를
  바꾸고 싶을 때 원본이 없다.
- 한 줄이라 기존 메모(티켓 경로)와 나란히 산다(F3 실측).
- `started` 만 있고 `finished` 가 없으면 **진행 중**이다 — 지금 얼마나 붙들려 있는지 보인다.
- 둘 다 없으면 아무것도 안 보여준다. 없는 것을 지어내지 않는다(INV-4).

### D3 — 착수 시각의 뜻: 일꾼이 뜬 순간

F13 이 이유다. PR 첫 커밋을 착수로 삼으면 T01 은 17분이 5분으로 줄어든다 — 캡틴이 알고 싶은
"이 티켓에 얼마나 걸렸나" 와 다른 값이다. 일꾼이 뜬 순간부터 재는 것이 그 물음의 답이다.

이미 끝난 티켓의 되짚기는 `data/<id>/brief.md` 의 mtime 을 착수로 쓴다(F7 — 정리 후에도 남는다).

### D4 — "약" 은 어림했다는 선언이고, 어림 규칙은 하나뿐이다

캡틴 문구가 "약 14분" 이다. 규칙:

- 1분 미만 → `약 1분` (0분이라고 말하지 않는다 — 일은 있었다)
- 1시간 미만 → 분 단위 반올림, `약 14분`
- 그 이상 → 시간+분, `약 2시간 5분`. 분이 0이면 `약 2시간`
- 진행 중이면 같은 값에 진행 중임을 덧붙인다

### D5 — 되짚기의 정직함

이미 끝난 티켓은 **PR 병합 시각**을 완료로 쓴다(F5). 이는 실제 완료보다 조금 늦다 —
firstmate 가 검증하고 병합한 시간이 섞인다. 그래도 되짚기의 최선이고, 앞으로의 기록은
정확하므로 시간이 지나면 되짚은 값은 소수가 된다.

🔴 되짚은 것과 실측한 것을 화면이 구분하지 않는다 — 캡틴이 원하신 것은 대략의 감이고,
구분 표시는 화면을 복잡하게 만들 뿐이다. 이 판단이 틀리면 후속으로 나눈다.

## 범위 밖

- gootte 가 GitHub 을 부르는 것 — D1.
- 걸린 시간을 정렬·집계·통계로 쓰는 것 — 지금 물음은 "이 티켓 얼마 걸렸나" 하나다.
- firstmate 가 시각을 적는 절차 자체 — firstmate 홈의 일이고 이 저장소 밖이다.
