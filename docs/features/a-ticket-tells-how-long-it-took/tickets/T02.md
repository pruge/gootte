# T02 — plan·steps 두 탭이 같은 문구를 보인다
Status: resolved (2026-08-27)

## Goal

`plan` 탭 카드 안 티켓 줄과 `steps` 탭 티켓 줄에 마우스를 올리면 T01 이 만든 걸린 시간 문구가 뜬다.
두 탭이 **같은 값을 같은 문구로** 보인다.

## Why this slice

캡틴이 지목하신 그 자리다. T01 이 값을 만들었으니 여기서는 옮겨 싣고 붙이기만 한다 —
어림 계산을 여기서 다시 하지 않는다.

## Produces

두 탭의 hover 문구. `ProcessRow` 에 실린 걸린 시간 문구.

## Consumers

- `code/web/frontend/src/components/plan/CardDialog.tsx:111` — 카드 안 티켓 줄
- `code/web/frontend/src/components/process/ProcessView.tsx:427` — steps 탭 줄

## Touched surfaces

- `code/web/contract/src/index.ts` — `ProcessRow` 에 문구 칸
- `code/web/core/src/plan/process.ts` — `ProcessRow` 조립 시 문구 옮겨 싣기
- `code/web/frontend/src/components/plan/CardDialog.tsx`
- `code/web/frontend/src/components/process/ProcessView.tsx`

## Explicitly out of scope

- 어림 규칙 — T01 이 소유한다. 여기서 다시 계산하면 두 탭이 갈라진다.
- `features` 탭 티켓 줄 — 캡틴이 지목하신 곳은 `plan`·`steps` 둘이다.
  나중에 원하시면 같은 값을 한 줄 더 붙이면 된다.
- 새 툴팁 부품 — 기존 관례는 `title=` 속성 하나다.

## Locked decisions

- 표시 자리는 `plan`·`steps` 두 탭 — 캡틴 지시 2026-08-27 원문.
- 문구는 `약 14분` 꼴 — 같은 지시.
- 🔴 기존 hover 문구를 지우지 않는다 — 나란히 붙인다(수용 기준 7).
- INV-1: 화면은 받은 문구를 그릴 뿐 아무것도 계산·저장하지 않는다.

## Scope

계약 한 칸, 조립 한 줄, 화면 두 곳.

## Implementation notes

- 문구가 없으면 **아무것도 덧붙이지 않는다** — 빈 괄호나 `-` 를 내지 않는다.
- 기존 `title=` 이 있는 자리에는 줄바꿈이나 구분자로 이어 붙인다. 기존 문구가 먼저다.
- 티켓 줄 전체가 이미 단추다 — 새 요소를 만들지 말고 있는 요소의 `title=` 을 쓴다.

## Acceptance criteria

1. `plan` 탭 카드 안 티켓 줄 hover 에 `약 N분` 이 뜬다.
2. `steps` 탭 티켓 줄 hover 에 **같은 문구**가 뜬다.
3. 진행 중인 티켓은 진행 중임이 문구에 드러난다.
4. 시간 기록이 없는 티켓에는 시간 문구가 안 붙는다.
5. 기존 hover 문구(상자 뜻 등)가 그대로 살아 있다.
6. `pnpm -C code/web verify` green.

## Verification

routine. 두 탭 시험에서 같은 픽스처로 **같은 문구**가 나오는지 함께 잰다 —
한쪽만 재면 갈라진 것을 못 잡는다.

🔴 화면 확인은 캡틴 검수(T03) 몫이다. 스크린샷을 찍지 않는다.
