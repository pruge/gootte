**Blocked by:** T07

## Goal

SoT 전환을 지침·관례 문서에 반영한다. 코드가 바뀌었는데 지침이 옛 관례를
말하면 다음 작업자가 거기로 되돌아간다.

## Why this slice

여기에 명시하지 않으면 이 전환이 위반으로 읽힌다.
