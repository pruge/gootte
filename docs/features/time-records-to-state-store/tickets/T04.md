## Goal

`bin/gootte`의 state.json 배지 갱신 훅을 `start` 전용에서 **전 명령**으로 확장하고,
잘못된 배지 계산(spec.md `Status:` 원문의 `done/dropped` 매칭 — 실물 원문은
`resolved/wontfix`라 항상 pending)을 티켓 기준 규칙으로 고친다.

## Why this slice

state.json 전환(T05)과 무관하게 MD 모드(타 관리대상)의 실제 결함이다.
worktree에서 `end`해도 메인 배지가 안 바뀌고(B1), 바뀌어도 틀린 값이 쓰였다(B2).

## Produces

- 훅이 start·end·pause·resume·cancel·drop 전 명령에서 발동
- 배지 계산을 **티켓 기준**(Time `finished=`·`started=` + `Status:` 원문)으로 —
  기능 수준 spec Status:가 아니라

## Consumers

- MD 모드(타 관리대상)의 worktree CLI 기록 — 메인 배지 신선도(INV-3)

## Touched surfaces
