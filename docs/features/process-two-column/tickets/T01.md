# T01 — steps 탭 2컬럼(1:2): feature 목록 + 선택된 feature 의 tickets
Time: started=2026-08-31T19:51:54+09:00 finished=2026-08-31T19:59:09+09:00

## Goal

`process`(steps) 탭 본문을 **2컬럼(1:2)** 으로 다시 그린다. 왼쪽(1)은 작업 대상 feature
목록, 오른쪽(2)은 선택한 feature 의 tickets 목록. **완료된 티켓도 숨기지 않는다.**

## Why this slice

현재 steps 탭은 단계별 묶음 격자라 단계가 여러 개면 좌우로 갈라져 한 눈에 훑기 어렵다
(캡틴: "읽기가 어렵다"). feature → 그 tickets 순으로 세로로 읽게 바꾸면 가독성이 바로 선다.

## Produces

- `frontend/src/components/process/ProcessView.tsx` — 2컬럼 재작성
  - 왼쪽 컬럼: `data.active` 카드의 feature 슬러그 목록(제목 포함), 클릭으로 선택, 기본 첫 번째
  - 오른쪽 컬럼: 선택된 feature 의 모든 티켓(구관례 `issues/` + 신관례 `tickets/`)을
    번호·제목·상자·안 읽음·처리중으로 표시. 완료·폐기도 그대로 보인다
  - 드래그(dnd)는 옛 격자에 유지 — 이 티켓은 읽기 화면만 바꾼다
- `frontend/test/process.test.tsx` — 2컬럼 테스트

## Consumers
