# T02 — `SettingsView` VSCode 레이아웃: 검색 + 좌측 카테고리 + 우측 폼

## Goal

T01 이 만든 본문 자리에 **VSCode 스타일 설정 화면**을 채운다 — 좌측 레일에 검색창과
카테고리 목록, 우측에 카테고리별 설정 폼. 설정 행은 VSCode 배치를 따른다:
**제목 → 다음 줄 설명 → 다음 줄 입력란**(세로 스택). 기존 세 항목(firstmate 홈 · 감시 폴더 ·
차단 목록)을 그대로 옮기고, 늘어날 항목 자리(예정: 테마)를 회색 배지로 함께 그린다.

## Why this slice

설정 폼 자체다. T01 이 셸(배치·토글)을, T03 이 옛 `SettingsDialog` 정리를 담당하므로 이
티켓은 `SettingsView` 안의 **내용과 레이아웃**에 집중한다.

## Scope

- `frontend` `SettingsView` — 좌측 레일(검색 + 카테고리) + 우측 폼.
- 카테고리: **일반**(firstmate 홈 경로) · **감시**(감시 폴더 목록) · **숨김**(차단한 작업 가지)
  + 예정(테마, disabled).
- 데이터 훅: `useSettings`, `useSaveSettings`, `useBlockedCopies` 를 `SettingsDialog` 에서 그대로
  옮겨온다. 검색 필터는 카테고리·항목 이름 매칭(순수 프론트).
- 저장: 명시적 "저장" 버튼(dirty 판정 + 성공 표시) — 현행 유지.

## Touched surfaces

- `code/web/frontend/src/components/settings/SettingsView.tsx` — 전체 구현
- `code/web/frontend/test/settings-view.test.tsx` (신규) — 폼·검색·저장 테스트
- 옛 `SettingsDialog` 의 훅 로직은 이 티켓에서 옮겨온다(파일 삭제는 T03).

## Explicitly out of scope

- `SettingsDialog` 파일 삭제·`settings-dialog.test.tsx` 이전 — T03
- 예정 카테고리(테마) 실제 구현 — 순수 배치 시연(disabled)
- 자동저장 — 별도
- URL 라우트 — 별도

## Locked decisions

- 🔴 **카테고리별 폼 전환** — 좌측 카테고리를 누르면 우측 폼이 해당 카테고리로 바뀐다.
  검색창에 입력하면 카테고리·항목이 필터링된다.
- 🔴 **행 배치(VSCode)**: 제목(굵게) → 설명(작게·회색) → 입력란 세로 스택. 입력란은 목록형이
  아니면 왼쪽 정렬 + 적당한 폭. 목록형(감시 폴더·차단 목록)은 첫 줄이 제목과 맞도록 위 정렬.
- 🔴 **저장 방식 유지** — 명시적 "저장" 버튼, dirty 시에만 활성, 저장 성공 표시("저장했습니다 —
  바로 적용됩니다").
- 🔴 **전역** — 카테고리·입력값은 프로젝트와 무관하다(T01 과 같은 이유).
- 존재하지 않는 경로는 서버 판정(`*Exists`, INV-3)을 그대로 경고로 릴레이한다 — 화면이
  재판정하지 않는다.

## Regression guards

- `code/web/frontend/test/settings-view.test.tsx` (신규) — 세 카테고리 렌더, 검색 필터,
  저장 호출 형상, 경로 경고 릴레이.
- 기존 `settings-dialog.test.tsx` 는 T03 전까지 유지(병존 회귀 감시).

## Acceptance criteria

1. 설정 화면에 좌측 레일(검색 + 일반/감시/숨김 + 예정:테마)과 우측 폼이 보인다.
2. 일반: firstmate 홈 경로 입력 + (tauri)찾아보기. 감시: 폴더 목록 추가/삭제 + 찾아보기.
   숨김: 차단 목록 + 해제(눈 아이콘).
3. 카테고리 클릭 → 우측 폼 전환. 검색 입력 → 카테고리·항목 필터링.
4. 저장 버튼은 dirty 시 활성, 누르면 PUT `/api/settings` + 성공 표시.
5. 존재하지 않는 경로 경고는 서버 값 그대로.
6. `pnpm -C code/web frontend verify` green.

## Verification

`pnpm -C code/web frontend verify` — `settings-view.test.tsx` + 기존 회귀. 수동 시나리오:
카테고리 전환 · 검색 · 경로 경고 · 저장 성공 표시.
