# T01 — 설정 화면을 본문 영역으로: gear 토글 + 헤더 타이틀 교체 + `SettingsView` 배치
Time: started=2026-08-30T18:43:56+09:00 finished=2026-08-30T18:47:05+09:00

## Goal

설정이 모달 다이얼로그(`SettingsDialog` 오버레이)로 뜨는 것을 없애고, gear 버튼을 누르면
**본문 영역**(평소 features/plan/steps 가 그려지는 자리)에 설정 화면이 **화면 교체**로 그려지게
만든다. 설정은 **전역 하나**다 — 어느 프로젝트를 골라도 gear 하나로 같은 설정이 열린다.
본문 헤더 타이틀은 설정이 열리면 `Settings` 로, 닫으면 선택한 프로젝트명으로 바뀐다.

## Why this slice

`MainPanel.tsx` 가 지금 `<SettingsDialog open>` 을 `fixed inset-0 z-50` 오버레이로 띄운다.
이 티켓은 그 **배치(셸) 변경**이다 — `SettingsView` 라는 본문 뷰를 하나 만들고, gear 를
토글로 만들어 화면을 바꾼다. 실제 설정 폼 내용(VSCode 스타일 레이아웃)은 T02 가, 옛
`SettingsDialog` 의 제거와 테스트 이전은 T03 이 한다.

## Scope

- `frontend` `MainPanel` — `settingsOpen` state → `SettingsView` 교체 렌더. gear 버튼이 토글로
  동작(`aria-expanded`), 헤더 타이틀 `Settings`/프로젝트명 전환.
- `frontend` `SettingsView` — **이 티켓에서는 빈 골격**(제목만)으로 두고, T02 가 내용을 채운다.
  옛 `SettingsDialog` 의 데이터 훅(`useSettings`, `useSaveSettings`, `useBlockedCopies`) 사용은
  T02 로 미룬다.
- URL 은 건드리지 않는다 — 라우팅(`?tab=settings`)은 범위 밖.

## Touched surfaces

- `code/web/frontend/src/components/main/MainPanel.tsx` — gear 토글 + 본문 뷰 교체 + 헤더 타이틀
- `code/web/frontend/src/components/settings/SettingsView.tsx` (신규) — 빈 골격
- `code/web/frontend/test/main-panel.test.tsx` (신규) — 토글·타이틀 전환 테스트

## Explicitly out of scope

- `SettingsView` 내부 폼 레이아웃(VSCode 카테고리·검색·행 배치) — T02
- `SettingsDialog.tsx` 삭제·`settings-dialog.test.tsx` 이전 — T03
- URL 라우트 `?tab=settings` — 별도
- 자동저장 전환 — 별도 결정

## Locked decisions

- 🔴 **설정은 전역** — 사이드바 프로젝트 선택과 무관하게 gear 하나로 열린다. 설정 화면에
  프로젝트별 상태를 싣지 않는다.
- 🔴 **헤더 타이틀**: 설정 열림 = `Settings`, 닫힘 = 프로젝트명(프로젝트 미선택 시 빈칸 유지).
- 🔴 **오버레이 제거** — `fixed inset-0` 백드롭·`backdrop-blur`·`role="dialog"` 를 쓰지 않는다.
  설정은 본문의 정상 뷰다.
- 🔴 **토글**: gear 를 다시 누르면 원래 뷰(탭이 유지한 features/plan/steps)로 돌아간다.
- 기존 `SettingsDialog` 는 T03 전까지 그대로 두어 회귀를 막는다(옛 경로가 잠깐 병존).

## Regression guards

- `code/web/frontend/test/main-panel.test.tsx` (신규) — gear 클릭 → `Settings` 타이틀 + 설정 뷰,
  재클릭 → 프로젝트명 + 원래 뷰.
- 기존 `code/web/frontend/test/settings-dialog.test.tsx` 는 T03 전까지 유지(병존 기간 회귀 감시).

## Acceptance criteria

1. 프로젝트 선택 후 gear 클릭 → 본문에 설정 화면이 뜨고 헤더 타이틀이 `Settings`.
2. gear 재클릭 → 프로젝트명으로 돌아가고 원래 뷰(features 등)가 그대로.
3. 설정이 오버레이가 아니라 본문 영역 안에서만 그려진다(백드롭 없음).
4. 프로젝트를 바꿔도 설정 화면은 같은 하나(전역).
5. `pnpm -C code/web frontend test` green.

`pnpm -C code/web frontend verify` — 컴포넌트 테스트 + 회귀. `main-panel.test.tsx` 신규
케이스가 핵심. 수동 시나리오: gear 열기/닫기 반복 + 탭 전환 후 다시 열기.
