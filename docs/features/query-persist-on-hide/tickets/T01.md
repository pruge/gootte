# T01 — dirty-flag + 닫힘 flush 로 교체

**Blocked by:** 없음 — 즉시 착수 가능

## Goal

캐시 변경마다 쓰는 구조를, dirty 표시 + 숨김·닫힘·60초 flush 구조로 바꾼다(S1).

## Why this slice

쓰기 폭증의 손잡이(`attachSaver`)가 한 함수에 모여 있어 한 슬라이스로 끝난다.

## Produces

- flush-on-hide 영속 저장. 쓰기 횟수가 시간당 수백 회 → 분당 최대 1회 + 닫힘 1회.

## Consumers

- `makeQueryClient` — 반환 전 `hydrateFromStorage`·`attachSaver` 호출부는 그대로.
- 새로고침 즉시 그리기(T07) — 읽기 경로(`hydrateFromStorage`)를 안 건드리므로 유지된다.
- 기존 프론트 테스트 — `makeQueryClient` 를 쓰는 곳이 있으면 cleanup 계약을 확인한다.

## Touched surfaces

- `code/web/frontend/src/lib/query.ts` — `attachSaver` 교체, cleanup 반환 추가.
- `code/web/frontend/test/query-persist.test.ts` — 신규.

## Explicitly out of scope

- 저장 범위·형식·키 변경. `hydrateFromStorage` 변경.

## Scope

- `query.ts` 저장 경로 + 신규 테스트. 읽기 경로·UI 금지.

## Implementation notes

- `attachSaver` 가 cleanup(`clearInterval` + 리스너 해제)을 반환하게 하고, 테스트에서 호출한다. 앱 본체(main.tsx)는 앱 수명과 같이 가므로 cleanup 을 안 쓴다(기존 WS 와 같은 규율).
- 인터벌은 dirty 일 때만 쓴다 — 조용할 땐 타이머가 돌아도 저장을 안 한다.
