# T01 — 인용된 경로가 부모 자리를 가로채지 못하게 한다
Time: started=2026-08-26T19:02:37+09:00 finished=2026-08-26T19:13:15+09:00

## Task

`findParentId` 가 자유 산문 안에서 기능 경로를 **인용**했을 뿐인 행을 부모로 뽑지 않게 한다.

현 규칙(`code/web/core/src/project/backlog-join.ts`):

```ts
function findParentId(tasks: readonly BacklogTaskDoc[], repo: string, featureSlug: string): string | null {
  const needle = `docs/features/${featureSlug}/`;
  return tasks.find((t) => t.repo === repo && !CHILD_ID.test(t.id) && t.note.includes(needle))?.id ?? null;
}
```

메모 전체에서 부분 문자열을 찾고 선착순으로 정하므로, 다른 작업이 자기 설명 안에서
그 경로를 인용하고 목록에서 먼저 오면 진짜 부모를 밀어낸다.
자식 id(`<가짜부모>-t<NN>`)가 없으니 그 기능의 티켓이 전부 상태 미표시가 된다.

고칠 방향(spec D2): 후보 중 **자식 행을 실제로 가진 것**(`<id>-t<NN>` 모양의 행이
백로그에 존재)만 남기고, 그 안에서 기존 선착순을 유지한다.
자식을 가진 후보가 하나도 없으면 기존 동작 그대로 선착순 첫 후보를 쓴다(spec D3).

🔴 **구현 형태를 이 티켓이 지정하지 않는다.** 아래 받아들임 조건을 만족하면 된다.
