# Issue tracker: `docs/features/` (로컬 마크다운)

이 저장소의 spec·티켓은 **`docs/features/` 아래 마크다운 파일**로 산다. GitHub Issues 는 쓰지 않는다 —
외부 기여자 유입이 없고, 이 저장소는 md 를 단일 SoT 로 삼는 규율(INV-1 — 손으로 유지되는 2차 SoT 금지)을 따른다.

## 레이아웃

```
docs/features/<기능-slug>/
├── spec.md                 ← spec 1개 = 파일 1개
├── issues/
│   ├── 01-<slug>.md        ← 티켓당 파일 1개. 의존 순서로 01 부터 번호
│   ├── 02-<slug>.md
│   └── 03-<slug>.md
├── adr/
│   └── NNNN-<slug>.md      ← 그 기능에 속한 결정 기록
└── _out-of-scope/          ← 거절·범위 밖으로 밀어낸 요청
```

## 규약

- **기능 하나당 디렉터리 하나**: `docs/features/<기능-slug>/`. slug 는 kebab-case 영문,
  문서 본문은 이 저장소 관례대로 한국어로 쓴다.
- **spec 은** `docs/features/<기능-slug>/spec.md` **하나**다.
- **구현 티켓은** `docs/features/<기능-slug>/issues/<NN>-<slug>.md`, `01` 부터 번호.
  🔴 **티켓 여러 개를 한 파일에 합치지 않는다 — 티켓당 파일 1개.** 티켓을 고치는 것이 곧 상태 갱신이므로,
  한 파일에 둘이 들어 있으면 상태가 어느 쪽 것인지 알 수 없게 된다.
- **triage 상태**는 각 파일 상단의 `Status:` 줄에 적는다. 정규 여덟 값과 서식은
  [`triage-labels.md`](triage-labels.md) 가 SoT 다.
- **의존(blocking)** 은 파일 상단의 `Blocked by:` 줄이다 — 아래 절 참고.
- **결정(ADR)** 은 그 결정이 속한 기능 폴더의 `adr/NNNN-<slug>.md` 에 쓴다. 평평한 `docs/adr/` 를 만들지
  않는다 — "영역 → 기능 → adr/" 이라는 접근 경로가 사라지기 때문이다.
- **코멘트·대화 이력**은 파일 **하단 `## Comments` 헤딩 아래에 append** 한다. 본문 중간에 끼워 넣지 않는다
  (본문은 "무엇을 짓는가", 코멘트는 "그 동안 무슨 일이 있었는가" — 섞이면 둘 다 못 읽는다).

## `Blocked by:` 의 의미

`**Blocked by:** 01, 02` — **같은 기능 폴더 안의 티켓 번호**에 대한 구조적 의존이다.
나열된 티켓이 **전부 `resolved` 되면 기계적으로 해제**된다. 사람이 따로 풀어 줄 것이 없다.

- 의존이 없으면 `**Blocked by:** 없음 — 즉시 착수 가능` 처럼 그 사실을 명시한다(빈칸으로 두지 않는다).
- 번호로 특정할 수 없는 외부 대기(다른 기능의 착지, 캡틴 결정, 상류 릴리스)는 `Blocked by:` 가 아니라
  `Status: blocked` 로 적는다. 둘의 구분은 [`triage-labels.md`](triage-labels.md) 참고.
- 같은 티켓이 둘 다 가질 수 있다.

## 다음 할 일은 계산되는 것이지 적어 두는 것이 아니다

**별도 원장 문서가 없다.** 상태는 티켓의 `Status:` 줄이, 순서는 `Blocked by:` 줄이 소유한다.
다음 할 일 = **frontier** — `issues/` 에서 `open` · unblocked · 미점유인 파일 중 번호가 빠른 것.
티켓을 고치는 것이 곧 상태 갱신이라 따로 갱신할 원장이 없고, 그래서 stale 해질 원장도 없다.
(이 저장소가 만드는 제품이 정확히 이 계산을 자동화한다 — INV-1·INV-4.)

## "이슈 트래커에 올려라" / "해당 티켓을 가져와라"

- **올려라** = `docs/features/<기능-slug>/` 아래에 새 파일을 만든다(폴더가 없으면 만든다).
- **가져와라** = 참조된 경로의 파일을 읽는다. 보통 경로나 번호를 직접 받는다.

## 기존 결정을 뒤집을 때

옛 파일을 고쳐 덮어쓰지 않는다. **새 ADR 을 그 기능 폴더의 `adr/` 에 쓰고 무엇을 뒤집는지 적는다.**
옛 결정 기록은 그 자리에 남는다 — 왜 그때 그렇게 정했는지가 다음 판단의 재료이기 때문이다.

> ⚠️ **미해결**: 기능이 여러 개로 늘면 전역 색인이 필요해질 수 있다. 지금은 폴더 목록으로 충분해서
> 만들지 않았다 — 필요해지는 시점에 결정한다.
