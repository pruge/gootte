# roadmap-doc-browser — wireframe

> 인라인 cd 브라우저(ADR-0001/0002). 이니셔티브 행을 펼치면 그 자리(체크리스트 있던 곳)에 브라우저.

## 1) 이니셔티브 펼침 = 기본 진입 (path = `todo/`)
```
▼ C  studio-fsm-unify                          진행 1 · 완료 4
  ┌────────────────────────────────────────────────────────┐
  │ 📁 <init> / todo                        ⟵ breadcrumb    │   ← 기본 path=todo/
  │ ──────────────────────────────────────────────────────  │
  │ ../                                          (상위로)    │   ← ".." = 이니셔티브 루트
  │ 📄 sfu-int-1-safety-contract.md         ✅ 완료          │
  │ 📄 sfu-drop-2-peel.md                    🔜 진행          │   ← 가상 todo/ (status badge)
  │ 📄 …                                                     │
  └────────────────────────────────────────────────────────┘
```

## 2) 상위(루트)로 cd — 이니셔티브 폴더 내용
```
  ┌────────────────────────────────────────────────────────┐
  │ 📁 <init>                               ⟵ breadcrumb    │
  │ ──────────────────────────────────────────────────────  │
  │ 📁 adr/                                                  │   ← 서브폴더 진입
  │ 📁 todo/                                                 │   ← 가상 폴더
  │ 📄 brief.md                                              │
  │ 📄 spec.md                                               │
  │ 📄 wireframe.md                                          │
  │ 📄 ledger.md                                             │   (있으면)
  └────────────────────────────────────────────────────────┘
```

## 3) 파일 클릭 → 기존 DocDrawer (우측, 재사용)
```
  [ … 브라우저 … ]        │ spec.md            [worktree] [보기|raw] [✕] │
                          │ ─────────────────────────────────────────── │
                          │  # roadmap-doc-browser — spec               │
                          │  ...(Markdown + mermaid 인라인 렌더)...      │
```

## 노트
- breadcrumb 세그먼트 클릭 = 그 레벨로 cd. `../` 행 = 부모로.
- dir 노드 = 폴더 아이콘 + 클릭 시 진입(자식 = path prefix 필터, 클라이언트). file 노드 = 클릭 시 DocDrawer(`DocRef`).
- 가상 `todo/` 노드만 status badge(진행/완료) — 실제 문서 파일엔 badge 없음.
- 좁은 인라인 세로 공간 기준(한 레벨 리스트). 트리 펼침 아님(ADR-0002).
